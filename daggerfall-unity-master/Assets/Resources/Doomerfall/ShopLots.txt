# Doomerfall shop lots (Shops 7). Read by DoomerfallShopLots.cs; edit and rebuild Daggerfall Unity.
#
# Each day a shop shelf (DoomerfallShopLedger) is under its share of the stock target, lots arrive until it is full.
# A lot is a small coherent bundle rolled with Daggerfall's own item and material code. A lot is never split below its
# core (the items that make it read as itself); items past the core are dropped when the shelf is full.
# Records are one per line: <record> <name> key=value ... Lists are comma separated; '_' in a name is a space.
# Item specs are <ItemGroup>:<template name> (Daggerfall's ItemEnums), <ItemGroup>:* for any template of the group,
# or Clothing:* for one piece of clothing for the player's gender.

# lot <template> core=<n> <BuildingType>=<weight> ...   Weights are relative within one shop type.
# Pawn shops take only estate, salvage and townsfolk lots (owner).
lot regular   core=1 WeaponSmith=64 Armorer=64 GeneralStore=72 Alchemist=85 Bookseller=85 ClothingStore=85 GemStore=85
lot estate    core=3 WeaponSmith=8  Armorer=8  GeneralStore=6  PawnShop=40
lot salvage   core=2 WeaponSmith=6  Armorer=6  PawnShop=25
lot caravan   core=3 WeaponSmith=12 Armorer=12 GeneralStore=10 Alchemist=15 Bookseller=15 ClothingStore=15 GemStore=15
lot bulk      core=4 WeaponSmith=10 Armorer=10 GeneralStore=8
lot townsfolk core=1 GeneralStore=4 PawnShop=35

# At most this many lots arrive on one shelf in one day.
setting lots_per_delivery 8
# Estate and salvage goods arrive worn: condition is a random percentage in this range, and value falls with it.
setting worn_estate 55-90
setting worn_salvage 35-80

# Estate sale: one dead adventurer's kit. One material roll for the whole kit, so it matches itself. Armor is plate of
# the kit's material, chain, leather or none. pieces = armor pieces (cuirass first), shield = % chance of a shield,
# side = % chance of a second weapon from sides, arrows = arrow stack size (bows), magic/clothes/books = counts.
estate warrior    weapons=Longsword,Broadsword,Claymore,Battle_Axe,War_Axe,Warhammer,Mace,Flail armor=plate pieces=2-5 shield=50 sides=Dagger,Shortsword side=40
estate knight     weapons=Longsword,Broadsword,Mace armor=plate pieces=4-6 shield=80
estate mercenary  weapons=Saber,Katana,Shortsword,Broadsword armor=chain pieces=2-4 shield=30 sides=Dagger,Tanto side=40
estate archer     weapons=Short_Bow,Long_Bow armor=leather pieces=1-3 arrows=10-30 sides=Dagger,Shortsword side=70
estate thief      weapons=Dagger,Tanto,Shortsword,Wakazashi armor=leather pieces=1-3 sides=Dagger side=40
estate spellsword weapons=Katana,Saber,Longsword armor=chain pieces=1-2 magic=1
estate mage       weapons=Staff,Dagger armor=none clothes=1-2 magic=1 books=1-2
# Every estate kit may also hold: potions (count range), a book (% chance), a ring or amulet (% chance).
setting estate_potions 0-2
setting estate_book 40
setting estate_jewellery 35

# Salvage: battlefield and dungeon gear, each piece rolled on its own (mixed kinds and materials), all worn.
# (Leaning to the nearest dungeon's monsters is backlog shop-salvage-lots.)
setting salvage_items 2-4

# Townsfolk: one odd item someone in town sold off (a wedding band, a lone helmet).

# Doom guns (guns enabled only). A shop whose Daggerfall stock includes weapons rolls this many Doom guns in each
# regular-supply lot from the loaded mod's guns (Resources/Doomerfall/WeaponValues.txt; any set, at the tier the file
# gives it), each tier rolled first by gun_tier_weights, a gun picked evenly within it, and then kept with Daggerfall's own stock rule: the gun's rarity must not exceed the shop's quality, and it stocks with
# chance (weapon chance of the shop) x 5 x (21 - rarity) / 100. Rarity comes from the gun's tier.
setting gun_rolls 3
# Tier weights common,uncommon,rare,veryrare,legendary: the tier is rolled first (falling by tier), then a gun in it.
setting gun_tier_weights 60,30,20,10,6
gunrarity common=4 uncommon=8 rare=12 veryrare=16 legendary=20

# Rare exceptions: a small fixed share of deliveries breaks the shop's pattern. Each building's days are cut into
# windows of window_days; a window is an exception window with chance share (the same in every game, from the
# building and the window number, never from the player). once = one shipment on the window's first day, on the
# first shelf; window = every delivery in the window, on every shelf. An exception lot arrives even on a full shelf.
# Plate and archery shipments wait on Shops 6 shop identity (owner question).
setting exception_share 0.04
setting exception_window_days 7
exception pawngun shops=PawnShop     mode=once   core=2 guns=1
exception siege   shops=GeneralStore mode=window core=1
exception onekind shops=WeaponSmith  mode=window core=1 village=1
