# Player installation guide

Lane: `installguide` (new). Model: Opus. Depends on nothing.

The other Doom mods (DRLA Arsenal, DRLA Monsters, DRLAX, Colourful Hell, and so on) are not committed: players get
them themselves. Owner (2026-11-27): "The other game mods are an exception but we should have an installation
instructions md file for players."

Write an installation guide for players (a new `.md` at the repository root or beside `manual.md`): what to install
(Daggerfall game data, the Doom IWAD, each required and optional Doom mod with where to get it and which version),
where each file goes, and how to start the game. Link it from `manual.md`.

Done when: following the guide on a clean folder gives a working game (checked by setting up a fresh folder from it),
and every mod Doomerfall loads is listed.
