- [20261127-170741] [oversight] Doom's close key can leave Daggerfall's character sheet stuck in a level-up with the attribute points unassigned. A level-up from ordinary skill use can then wipe those points. Evidence: DoomerfallUi.OnClose (DoomerfallUi.cs:579-593) calls DaggerfallUI.Instance.PopToHUD(), a plain PopWindow. That skips DaggerfallCharacterSheetWindow.CheckIfDoneLeveling, so pressing P on a leveling sheet closes it with leveling=true and the points only in statsRollout. This run's paired test showed it (SXPENDINGKEPT: the sheet reopened still leveling). If a skill then rises from use (after rest or travel) and makes another level ready before the player reopens the sheet, the next open calls UpdatePlayerValues, which raises the level again and resets StartingStats, WorkingStats and BonusPool, so the first level's points are lost. The Skill XP card now blocks purchases in this state, but use-based level-ups are outside it. Confidence: medium. The sheet-state part is verified by the test; the use-based sequence is from reading the code and was not run.
