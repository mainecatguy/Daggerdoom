# 20261126-220430: assault rifle guns are Automatics; "Type:" when singular

## Goal

The Assault Rifle Chaingun, Assault Rifle Minigun and Autocannon count as Automatics (skill and description), and a
gun's Info line reads "Type: X" with one type, "Types: X, Y" with two. Owner, 2026-11-26: "Those all sound like
automatics, create a task to tag those as automatics. Also, it should be Type: if it is singular."

## Plan (as built)

1. **Category.** The three guns carry DRLA's single-shot rifle token, which made `BothWithTokens` return Precision
   (no skill). `DoomerfallWeaponCategory.IsOwnerAutomatic` names the three classes (run-time lookup, so nothing
   without DRLA). In `BothWithTokens`, the Precision line skips them and the next line returns Automatic. It sits
   after the Pistol, Explosive, Energy and Shotgun checks, so the precedence is unchanged for every other gun; these
   three have none of those signs anyway (none was anything but Precision before). Because the skill code (`Both`)
   and the description (`BothOfClass`) share `BothWithTokens`, both change together.
2. **"Type:" / "Types:".** `DoomerfallDoomItem.TypesLine` (Daggerfall side) picks "Type" when Doom's types text has no
   comma, "Types" when it has one (Doom joins types with ", "). An empty list still reads "Types: none" (zero is
   plural; the goal only asks about one and two).
3. **Tests.** `run_weaponcat_test.py` expects the three guns to be `automatic` (slot 5) and still checks they never
   get the Rifles slot. `run_weapontypes_test.py` samples them as "Automatic". New
   `tools/weapon_types/check_types_line.py` copies `TypesLine` out of the C# file, compiles it with PowerShell
   `Add-Type`, and checks the singular, plural and none lines without Unity.
4. **Manual.** The example now reads "Plasma Rifle. Type: Energy", and the Automatics skill line names the three guns.

No engine change: only ZScript in the Doomerfall mod and one C# method. No other gun's category changes (the weapon
types test compares the class answer with the held answer for all 167 DRLA token guns and 9 stock guns).
