# Attributes in Doom 01: Strength and Speed (run 20261126-225318)

Goal: Strength gives melee damage +0% at 0 to +100% at 100 (Melee skill weapons and Hand-to-Hand); Speed changes Doom
movement speed, -25% at 0, normal at 50, +25% at 100. Live values, above 100 counts as 100. Manual "Attributes" section.

## Plan (as carried out)

1. Engine: one read-only native `Actor.DD_SheetStat(stat)` beside `DD_SheetSkill`: Daggerfall's live attribute from
   the character sheet Daggerfall already sends (`DFB_SHEET_STATS_LIVE`), -1 without a Daggerfall character. No bridge
   header change, no new data from Daggerfall.
2. Mod (`mods/doomerfall/src/zscript/DoomerfallAttributes.zs`): an inventory item `DoomerfallAttributeEffects` with
   - `GetSpeedFactor` = 0.75 + Speed/200 (Doom multiplies every inventory item's factor in `PlayerPawn.TweakSpeeds`,
     so it composes with DRLA and power-ups);
   - offensive `ModifyDamage`: x (1 + Strength/100) when the owner hits something else while holding a weapon that
     `DoomerfallWeaponCategory.Of` files as Melee or Unarmed (fists = Hand-to-Hand).
   An `EventHandler` gives the item to each player while a Daggerfall character exists. Without Daggerfall the item is
   never given, so stock Doom and plain WADs are unchanged.
3. Daggerfall test hook `-dfattrtest [seconds]` (`DoomerfallAttributesTest.cs`, one line in `DoomerfallBridge`):
   sets permanent Strength and Speed to 0, 100, 50, 10 in turn, twice.
4. Test `tools/attributes/attributes_paired.py` (+ harness `attributes_paired.zs`, its own pk3) in `stock` and `paired`
   modes.
5. Manual: new "Attributes" section.

## Why Doom computes it (ownership)

Daggerfall owns the character sheet and passes it to Doom; Doom applies it for fast per-hit calculation (AGENTS.md
pillar). The sheet was already being sent; only the read is new. The alternative, adding the Strength element to
Daggerfall's `DoomerfallDamageBonus` (one total multiplier), does not work: Daggerfall cannot tell a melee hit from a
gun hit, because it applies to all player damage. Movement is Doom's.

## Failed approaches and gotchas

- In the offensive `ModifyDamage` call, P_DamageMobj passes the **target** in the `source` parameter. Checking
  "source is the owner" (my first draft) would have disabled the bonus; the code skips only `source == owner`
  (self-hits).
- `+forward` on the command line runs `forward` (the `+` is stripped). `++forward` runs, but held buttons do nothing in
  a UZDoom window that is never active (quiet_run's private desktop): the player never moved. The harness now supplies
  the walk itself each tic exactly as `PlayerPawn.MovePlayer` does (`TweakSpeeds`, `Speed / 256`, friction
  `movefactor`, `ForwardThrust`), so physics and the speed factor path are the real ones; only the key press is
  simulated.
- The `carbine-play` launcher predates this branch's bridge layout (attach error -5, `DFB_ERR_LAYOUT`); the paired test
  now installs this checkout's launcher and bridge DLL as `scripts/play/install.py` does.
- The demo's `play.bat` uses `start`, so its games outlive quiet_run's timeout. My demo smoke launch left UZDoom
  (pid 51536), Daggerfall Unity (43540) and the launcher (36920) idling at the title on private desktops; I could not
  stop them (process kill needs approval). End them in Task Manager, then delete the demo's `run` folder so the first
  launch applies the key binds.

## Known gaps and judgment calls

- "Holding" decides melee: damage the player deals while the ready weapon is Melee or Unarmed gets the bonus. A rocket
  fired before switching to fists that lands after the switch would get it; a projectile a melee weapon fires gets it.
  Both rare. Gun bashes do not exist in DRLA as far as I know.
- The Strength bonus multiplies with Daggerfall's damage bonus (ammo and gun material), as every bonus in
  `gamedesign/damage.md` multiplies.
- Speed scales walking and running the same, on the ground and in air control (TweakSpeeds); it does not change jump
  height or climbing speed (DoomerfallClimb uses `Speed`, not the factor).
- Daggerfall's own Strength damage modifier and Speed walk speed are unused in Doom, as before (Daggerfall's 3D world
  is off).
