# Shotguns perks (skillperks 04), run 20261127-033904

## Plan
1. Follow the Automatics pattern: Daggerfall decides the rules from the live Shotguns skill and sends them in the
   character sheet; Doom's mod applies them to guns whose skill is Shotguns (`DoomerfallWeaponCategory.SkillSlotOf`).
2. Pellets need an engine hook (stock and DRLA shotguns fire pellets inside `A_FireShotgun`/`A_FireBullets`).
3. Fake-peer test with the stock Shotgun and DRLA Shotgun, Double Shotgun, Assault Shotgun (plus Autoshotgun); paired run
   with real Daggerfall showing a wall slam; startup checks; manual; demo.

## What was built
- **Bridge:** sheet format 8, `DFB_SHEET_INTS` 168, `DFB_SHEET_SHOT_*` 162-167 (damage bp, reload cut bp, pellet bp,
  knock strength bp, slam damage, collision damage). Bindings regenerated. `tools/automatics/automatics_test.py` moved to
  the new sheet size (it writes the sheet itself).
- **Daggerfall:** `DoomerfallShotgunsRules.cs` (owner numbers), one line in `DoomerfallSheet.Fill`, perk texts marked
  built and rewritten to say what was built (the old 100 text promised "reload faster still", which is open).
- **Engine (UZDoom ZScript, 4 small edits, each marked `Doomerfall`):** `Inventory.ModifyPellets` (virtual, returns its
  input), `StateProvider.DD_Pellets` (asks the player's items), called by `A_FireBullets` (spread branch),
  `A_FireShotgun` and `A_FireShotgun2`. No item overrides it unless the Doomerfall mod gives one, and the mod gives it
  only while a Daggerfall character's sheet is valid, so DOOM.WAD E1M1 is unchanged.
- **Doom mod:** `mods/doomerfall/src/zscript/DoomerfallShotguns.zs`: a perk item on the player (damage, pellets, reload)
  and a static handler (knockback, slam, collision).

## Engineering calls (within the owner's rules)
- **Damage** +0.75% per skill point, +75% at 100; per pellet, hitscan pellets only (puff inflictor while a Shotguns gun is
  held, like Automatics).
- **Pellets:** count x1.5 / x2, fractions rounded up with their chance, so a 1-pellet call (the Assault Shotgun fires 7
  separate 1-pellet calls) gets 2 pellets half the time. Only the spread branch of `A_FireBullets` is hooked: a single
  accurate bullet (numbullets 1 on a first shot) is not a pellet volley.
- **Faster reload, in whole tics (the card asked how):** while a reload runs, each weapon frame entered adds
  `tics x 35%` to a running total and loses the whole tics of that total, never going below 1 tic (0-tic frames stay
  0). The carry resets at each reload. So 1-tic frames cannot shrink and the cut over a reload is about 35% of its
  multi-tic frames. Measured: stock Shotgun 34 of the 44-tic shot cycle are pump frames, cut 11 per shot (44 -> 33,
  25% faster firing); DRLA empty-magazine reloads: Shotgun 34 -> 23, Double 56 -> 40, Assault 69 -> 46, Autoshotgun
  79 -> 52 tics (29-34% shorter overall, 34-35% of the multi-tic frames).
  What counts as a reload: a DRLA gun's reload (reload pressed, fire with an empty magazine, or DRLA autoreload after
  the shot that emptied it); for a gun with no Reload state (stock Doom), every frame after the firing frame until the
  gun is ready or fires again (the pump / break-open reload).
- **Knockback** once per shot per enemy (pellets that hit it in one tic): speed = 16 units/tic x strength (1 at 75, 2 at
  100) x min(1, pellets hit / (14 x pellet bonus)) x min(1, sqrt(100 / mass)). 14 is the DRLA Double Shotgun's blast,
  so it gets the full effect point blank; 7-pellet guns get half. Stagger (pain state) when the shove is at least 4
  units/tic, so a light shove on a heavy enemy does not stun-lock. Respects `DONTTHRUST`. Doom's own per-pellet thrust
  still applies on top.
- **Wall slam:** for 35 tics the knocked enemy is watched; if its velocity move was stopped by a line
  (`MovementBlockingLine`, which UZDoom clears each tic before the move) and it lost over half its speed, it takes
  `round(slam x min(1, speed before impact / strongest launch))`, once per shot. Same for hitting another actor: both
  take the collision amount. Damage is dealt by the player with no inflictor, so other perks do not add to it.
- **Collision damage is built but sent as 0** (open; owner tentative 200/400). The tests prove it with 200.

## Failed approaches
- The paired run on DDOVER01 (the city): no wall reachable from the start. Line traces only hit rising terrain, the town
  loads ~40 s in, and the one "wall" a walking probe found 4096 units away was the edge of the loaded overworld window:
  teleporting there made the treadmill recenter the map by a tile (6144 units), so the target and the wall moved. The
  paired run now puts Doom on Doom 2 MAP01 (still real Daggerfall driving the skill) and finds a real wall by walking a
  target-sized probe. `run DDOVER01` still works as an argument for a later try.
- The Super Shotgun is Doom 2 only, so the E1M1 test cannot select it; it is hooked like the Shotgun (`A_FireShotgun2`).

## Known gaps
- Hitscan pellets only: a Shotguns gun that fires projectile pellets gets no damage bonus or knockback (none found among
  the tested guns). The pellet count hook does cover `A_FireBullets` missiles.
- The Autoshotgun, the Assault Shotgun and the Shotgun all fire 7 pellets per shot, so with the decided pellet rule
  they knock equally; making auto shotguns the worst needs the open slower-shotgun factor.
- A shot that kills does not knock (dead enemies are skipped).
- For a DRLA gun whose magazine is emptied with autoreload off, the frames after the last shot are not shortened
  (only an actual reload is).
