# Quest follower faces on Doom's HUD (run 20261124-112251)

Card `questfaces`. Branch `agent/questfaces-20261124-112251` (lane-location worktree), from `integration` at d501eed.

## Plan

1. Daggerfall stays the owner of the face list (`EscortingNPCFacePanel`). A Doomerfall class watches the panel and
   writes the faces it shows into a bridge bulk slot whenever the panel refreshes. That covers `add face`, `drop face`,
   a quest ending, New Game and loads (the panel clears on `OnStartLoad` and refills from the save) with no hooks of
   its own.
2. The slot carries the pixels, so Doom draws exactly the portrait Daggerfall would, mod replacements included, and
   Doom needs no Daggerfall file readers.
3. Doom turns each face into a runtime texture and draws a small row after the status bar.
4. Test hook on both sides (`-dffacetest`), each in its own file: Daggerfall adds A, adds B after its half of a save,
   drops A after a load; Doom saves, loads and takes a screenshot at each state.

## Design calls (engineering)

- **Bulk slot, not events.** The face list is state, not a stream, so it uses the sheet's pattern: `DFB_FACES_SLOT`
  (slot 1, written by Daggerfall). A bulk slot keeps its last version, so a Doom that reconnects or loads later still
  reads the current list. No event kinds were needed, so 190-194 stay unused.
- **Pixels in the slot.** Up to 3 faces (Daggerfall's own HUD limit, `maxFaces`), each at most 64x64 BGRA, plus each
  face's display size in Daggerfall's 320x200 HUD units (faction faces are 64x64 drawn at 48x48). 49 KB at most,
  inside the 64 KB slot.
- **Two-line change in Daggerfall's panel.** `HUDEscortingNPCFaces.cs` gains `RefreshCount` (bumped in
  `RefreshFaces`) and a read-only `FacePanels`. Nothing else in Daggerfall's face code, save format or quest actions
  changed.
- **Doom keeps nothing.** Doom's copy is unsaved globals rebuilt from the newest slot version; a version that fails to
  parse clears the row.

## Placement

Doom draws the faces at 0.45 of Daggerfall's size, in a row from (4, 44) in 320x200 units scaled to the screen height:
top left, under the pickup and Daggerfall message lines, away from the combat HUD at the bottom. Hidden with the HUD
(`hud_toggled`), on the automap, behind Daggerfall's menus, and when the camera is not the player. See the play-test
list.
