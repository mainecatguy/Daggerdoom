## Findings
- No merged feature broke another in these runs. No game code was changed.
- Test-tool drift found (not game bugs): New Game's class double-click (fixed in the driver), the monster-death harness
  predating loot windows, the hotkeys test assuming DRLA X's start gun is on key 2 with a magazine, and tools sharing one
  saves folder (a later test deletes an earlier autosave, so run each save/load pair back to back).
- Every Daggerfall run logs one `NullReferenceException` in `DaggerfallUI.SetupSingleton` at startup. It is in all 29
  older review folders too, so it is old and harmless here.

## Failed approaches
- Pinning Doom's window size with `+vid_defwidth/height` did not help the New Game driver; the surface it reports is
  Daggerfall's (1920x1080). The Enter fallback fixed it.

## What to try (also at the top of play.bat)
1. New Game: make a character in Daggerfall's real creation screens. You wake in Privateer's Hold.
2. Privateer's Hold: rooms hold a stimpack, clip, or shells (walk over them). Kill a monster, look at its drop, press Use.
3. Pick up a Doom gun with Use. If nothing is on its number key yet it is drawn at once; otherwise put it on a hotkey from the inventory (I) and press that key to swap.
4. Look at a ground item or monster and press Q for Info.
5. Climb a wall: walk into it and keep pressing forward. Back climbs down; holding still lets you shoot.
6. Leave the dungeon and walk into town. Townspeople walk the streets; at night they are inside their homes.
7. Use on a townsperson to talk. Use on a shopkeeper for Daggerfall's shop menu.
8. Crouch and Use on shop goods to steal. If you are seen, guards come and fight you, Doom style.
9. Press K for the travel map. Hover a place to see its danger hint.
10. Save from Doom's menu, quit, start play.bat again, and load: both games come back together.
