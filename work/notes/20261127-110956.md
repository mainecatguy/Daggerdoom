# Enter and exit messages for town buildings (run 20261127-110956)

Goal: show in Doom the messages Daggerfall Unity shows when the player enters or leaves a town building, in the same cases.

## When Daggerfall Unity shows a building message (from the code)

Only on **entering from outside through a building door** (`PlayerActivate.ActivateStaticDoor`, the
`door.doorType == DoorTypes.Building && !IsPlayerInside` branch). **Leaving a building shows nothing.** The message
appears only when `PlayerActivate.buildingGreetingsEnabled` is true, which is the default; mods can turn it off.

| Building | Condition | Message |
|---|---|---|
| Shop: Alchemist, Armorer, Bookseller, ClothingStore, FurnitureStore, GemStore, GeneralStore, PawnShop, WeaponSmith (`RMBLayout.IsShop`) | Every entry, including after picking or bashing the lock | Shop quality text, picked from the building's quality (1-20): RSC 266 (18-20, "Incense and soft music..."), 267 (14-17), 268 (8-13), 269 (4-7), 270 (1-3). How it shows depends on the `ShopQualityPresentation` setting: 0 (default, classic) a message box, 1 HUD text held `ShopQualityHUDDelay` seconds, 2 nothing. |
| Home: House1 to House4 | Unlocked (Daggerfall's open hours: 06:00 to 18:00, or an active quest site), not broken into, not a Thieves Guild or Dark Brotherhood house, not owned by the player | A random home greeting from RSC 256, as a message box. |
| Anything else (taverns, temples, guild halls, palaces, House5/6, houses for sale, the player's own house, homes broken into) | | Nothing. |

In Daggerfall Unity the message box comes up **before** the player steps in; the transition waits until it closes
(`BuildingGreetingPopup_OnClose`).

Other building-related messages that are not entry messages, so out of scope here:
- Info on a building names it, and adds "closed" text out of hours (`ActivateBuilding`). Doom's Info already sends this
  (`DoomerfallInfo`).
- "You are entering %s" / dungeon flavour text: on entering a **location's** rectangle while outdoors
  (`PlayerEnterExit.PlayerGPS_OnEnterLocationRect`), not a building. Already forwarded by the HUD text hook.
- "Locked." / lockpicking messages at a locked building door: Doom has no building locks yet (`DoomerfallLocks.cs`
  header), so they do not arise.
- "This house has nothing of value": shown if Daggerfall's interior layout fails; already HUD text, forwarded.

## Plan

1. Move the greeting code out of `ActivateStaticDoor` into a public `PlayerActivate.PresentBuildingGreeting(buildingKey,
   type, unlocked, brokenIn)` (pure refactor, same behaviour), so Doom's path runs exactly Daggerfall's code.
2. In `DoomerfallTransition.Enter` (Daggerfall following Doom's door), call it after `TransitionInterior` for a real
   walk-in, never for a load (Doom also sends a transition when a load restores the player indoors; `LoadRunning` tells
   them apart).
3. Delivery to Doom needs no new code: a message box Daggerfall opens by itself is asked for with `DFB_KIND_UI_ASK` and
   Doom shows it (`DoomerfallUi.AskForOwnWindow`); HUD text goes through `DoomerfallHudMessages`.
4. Paired run: `tools/building_greeting/building_greeting.py run shop|house|tavern`.

## Engineering calls

- **Locked buildings.** Doom does not lock building doors yet, so the player can walk into a building Daggerfall holds
  locked. The only way to be inside one in Daggerfall is to break in, so that entry counts as broken in: a shop still
  shows its quality text, a home gives no greeting. This keeps "same messages in the same cases" for every case
  Daggerfall can reach.
- **Order.** In Doom the player is already inside when the box appears, because Doom moved first and Daggerfall follows.
  Holding Doom outside until the box closes would change Doom's door flow, which is out of scope.

## Play-test list

- Walk into a general store (demo). Daggerfall's shop quality message box appears over the Doom view; a click or key
  closes it and play resumes.
- Walk into a house between 06:00 and 18:00: a greeting box. At night (or a Thieves Guild house): nothing.
- Walk into a tavern or temple: nothing. Walk out of any building: nothing.
- Judge whether a message box on every shop entry feels too intrusive in a shooter. Daggerfall Unity's setting
  `ShopQualityPresentation=1` turns it into HUD text and `=2` turns it off; both are honoured.
