# Distant terrain LOD (distantlod 01), run 20261126-213115

## Plan

1. Find what already draws beyond the map. Result: only the town mesh seen from the overworld (`DFMesh_DrawLod`) and
   town billboards. Beyond the 128 x 128 tile window, or beyond a location map's 64-tile terrain margin, nothing.
2. Add a render-only ring of distant terrain built from the treadmill's own height function (`SampleVertex`), in world
   tile coordinates, excluding the tiles the running map draws itself. No state, nothing saved: it is a pure function of
   the world tile, so every map that shows a piece of ground shows the same heights.
3. Test with screenshots: the overworld before and after a treadmill shift from the same world point, and a dungeon
   exterior (Privateer's Hold, group 7154), each with the view on and off.
4. Distant trees (wilderness nature) and a DFU comparison, if budget allows.

## Choice: static mesh pass, not a sky viewpoint

- UZDoom sky viewpoints (skybox portals) draw a second scene at a fixed offset with its own scale. A Source-style scaled
  skybox would put the far terrain at a smaller scale, so it would need its own parallax handling as the treadmill moves,
  and it is drawn behind everything with a cleared depth buffer, so the seam with the real terrain cannot be exact.
- The existing static-mesh layer (`hw_dfmesh.cpp`) already draws vertex buffers in world position outside Doom's sector
  visibility, with Daggerfall's fog and daylight. The new pass (`hw_ddhorizon.cpp`) follows it. The ring is real-scale
  geometry, so parallax is correct by construction and the depth buffer resolves the seam.
- Doom's far clip plane is 65,536 units (`DFrameBuffer::GetZFar`, used by stock games too, so not changed). The ring
  goes out to 60,000 units (312 tiles, about 2.4 map pixels). Daggerfall Unity's default terrain distance is a radius
  of 3 map pixels, about 2.5 km; 60,000 Doom units is about 2 km.

## What was built

- `UZDoom/src/rendering/hwrenderer/scene/hw_ddhorizon.cpp` (new). One vertex buffer, rebuilt when the map's own tile
  rectangle moves (treadmill shift, new map) or the player enters another 32-tile chunk. Coarse quads of 4 x 4 tiles,
  and a fine band (1 tile per quad) 32 tiles wide around the map's own tiles, so the seam vertices are exactly the
  heights the map uses. The band's outer edge takes the coarse edge's interpolated height, so the two meet without
  cracks. Heights are cached by world chunk (a cache only; dropped when large).
- `dd_treadmill.cpp`: `DDTreadmill_HorizonFrame` (where world tiles sit on this map, and the map's own tile rectangle:
  the treadmill window, or a location map's `visual` rectangle) and `DDTreadmill_HorizonHeight`.
- One call in `hw_drawinfo.cpp`, next to `DFMesh_DrawLod`. `dd_horizon` (archived CVAR, default on) turns it off.
- Inactive unless the treadmill reports a Daggerfall exterior: off on stock maps, interiors and dungeons.

### Lighting

The first version lit the ring at full brightness. On the overworld it showed as a lighter band, because Doom darkens
its own floor with distance. On the overworld the ring now uses the player sector's light and Doom's distance fade
(`SetColor` / `SetFog`), the same as the window's floor, and the seam no longer shows. On location maps it uses the
Daggerfall mesh's lighting (Daggerfall daylight and fog).

### Known gaps

**This goal is not met.** Terrain objects and the Daggerfall Unity comparison are missing.

- **No distant trees or towns.** The overworld window itself has no wilderness trees today; only town maps have them,
  baked by the converter with a per-town random sequence, so they are not the same function of the world tile.
  Making trees the same on every map needs one placement function that depends only on the world tile. The question
  for the owner is in the run report. Distant towns are the separate backlog item `distant-town-view`.
- **One ground texture.** The ring uses `DFGROUND`, the overworld floor's grass tile. It has no water, dirt, stone or
  climate variation. Neither does the overworld window yet.
- **The far edge** is a circle 60,000 units out, cut by Doom's 65,536 far clip. In clear weather the edge is a hard line
  against the sky. Daggerfall Unity has a similar edge at its terrain distance.
- **Drawn after the map's own geometry in Part 1.** The sky portal did not paint over the ring in any screenshot, so
  no change to portal order was needed.
