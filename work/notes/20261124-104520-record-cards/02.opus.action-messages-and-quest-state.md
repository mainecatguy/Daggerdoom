# Records 2: action records that show text, ask riddles, talk, or set quest state

Read D:\dev\DoomDaggerfall\AGENTS.md first. The survey is `work/notes/20261124-104520-record-types.md`, section 1.1.

## Goal
Dungeon action records of types 11 (show text), 12 (text with input, riddles), 29 (dialogue), 31 (set quest global)
and 99 (door text) do what Daggerfall Unity does when Doom triggers them. Today they reach
`DFActionRules.Request` in `tools/dungeon_converter/action_objects.zs:10-15`, print `DFRULE`, and stop.

## Where they are
- Type 11: 3 models and 3 flats (Sentinel, Mantellan Crux).
- Type 12: 2 models and 4 flats. The riddles in Shedungent, Daggerfall and Mantellan Crux. `AnswerAccepted`
  (`action_objects.zs:18`) has no caller yet.
- Type 29: 79 flats, nearly all on NPC flats (Scourg Barrow, Direnni Tower, Shedungent, Daggerfall).
- Type 31: 2 models (Mantellan Crux, Lysandus' Tomb). Main quest.
- Type 99: 120 models, mostly castle doors. DFU shows the text in Info mode, and a non-Info click can turn castle
  guards hostile.
- Types 16 and 17 (lock, unlock) also log only. Door locks wait on the owner (backlog *Locked doors with
  Daggerfall's requirements*), so here only make sure they keep logging and do not break the chain.

## Approach
Doom reports the trigger over the bridge with the record's identity (block, file position) and Daggerfall runs its
own `DaggerfallAction` behaviour for that record, with its own text (`TEXT.RSC`) and windows shown through Doom, as
shops and talk already do. Riddle answers come back as `AnswerAccepted`. Prefer reusing DFU's action code over
copying it.

## What must stay true
- Movers, doors, teleports and chains behave as before (`action_regress.py`, `special_door_regress.py`).
- Each trigger fires once per DFU rules, also across save and load.
- Type 31 sets the same quest global DFU sets.

## How to prove it
- Paired session in Shedungent: walk to the riddle, answer wrong then right, see the chain open only after the right
  answer. Log both sides.
- Paired session in a castle: Info on a type 99 door shows Daggerfall's text.
- Scripted trigger of each type in a test map, checking Daggerfall's log for the matching action.
