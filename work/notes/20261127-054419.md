# Remove shields from the game for now (goal noshields, 2026-11-27)

## Plan

1. Find every place Daggerfall creates a shield or equips one.
2. Remove shields there, only in a bridge session (plain Daggerfall Unity keeps them), with a one-line hook each and
   the logic in one class, `Doomerfall/DoomerfallShields.cs`.
3. Old saves: keep the shield as a carried item, take it off if equipped, refuse equipping.
4. Test in a paired New Game run: survey loot and shop stock through Daggerfall's own generators, try to equip,
   save and load a game with an equipped shield (`-dfshieldtest`, `tools/shields/shields_paired.py`).
5. Backlog card `shield-support` (the owner asked for one).

## Where Daggerfall makes shields, and what changed

| Source | Code | In a bridge session now |
|---|---|---|
| Random armor: loot piles, enemy loot tables, house containers, magic items | `ItemBuilder.CreateRandomArmor` | a shield roll is rolled again among the other armor |
| Shop shelves (armorer, weapon smith, pawn shop, general store ...) | `DaggerfallLoot.StockShopShelf` | shield templates are skipped |
| Class enemies' left hand (50%) | `ItemHelper.AssignEnemyStartingEquipment` | no shield (the dice roll still happens, so seeded loot is unchanged otherwise) |
| Character background answers (BIOG items) | `BiogFile` | a shield item is not given |
| Quests' random armor (subclass -1) | `Questing/Item.cs` | the subclass is rolled again |
| Create Item spell (Steel Buckler) | `CreateItem.cs` | the Steel Buckler is not in the list |
| Equipping (inventory, any other caller) | `ItemEquipTable.EquipItem`, `DaggerfallInventoryWindow.EquipItem` | refused; the inventory shows "Shields cannot be used." |
| Old save with a shield equipped | `DoomerfallShields.OnLoad` | taken off after load; Daggerfall's armor values drop the shield bonus |
| Starting gear | `ItemHelper.AssignStartingGear` | never had shields; unchanged |
| Knightly order armor reward | `KnightlyOrder` | already only templates 102-108 (no shields); unchanged |

A reroll rather than a dropped item is the literal "not in the table": an armor drop stays an armor drop. Without it a
third of all random armor (4 of 11 templates) would vanish, which would change how much armor the game gives.

**What happens to a shield in an existing save:** it stays in the inventory (or container) as an ordinary item. It can
be carried, dropped and sold, but not equipped. If it was equipped, loading takes it off and logs
`shields: took off "<name>"` to the bridge log. Nothing is deleted, because Daggerfall owns inventory and the owner
plans to bring shields back.

**Known gap (question for the owner):** the two quest artifacts that are shields, Auriel's Shield (quest B0B71Y03) and
Spell Breaker (50C00Y00), still exist so those quests keep working. They cannot be equipped either.
