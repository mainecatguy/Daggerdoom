# 2026-11-27 18:54 — Attribute rework: Strength and Agility gun damage, no dodge, Luck super crit

Owner decision: `gamedesign/decisions/20261127-attribute-rework-owner.md` (in the main checkout; not yet on this branch).

## Plan

1. Port the stopped Personality run's AttackKind idea (9c7bbb35, read only, not merged) into
   `DoomerfallAttributeEffects`, returning the attacking weapon's two categories and class as well, so one function
   decides melee / gun / neither and which tags the gun has. Drop its Personality rule.
2. Strength gun curve, Agility gun curve (two parts for rifles and pistols), Luck 5x super crit, all in
   `DoomerfallAttributeEffects.ModifyDamage` (the shared rule place Strength already used).
3. Remove Agility's dodge (`DoomerfallAgility.zs`), keep reload/switch speed.
4. Fake-peer test (stock, DRLA, no bridge) and paired test (real Daggerfall Unity sets the attributes).
5. Update the old Agility and Strength tests whose expectations encoded the old rules. manual.md Attributes.

## What was built

- `mods/doomerfall/src/zscript/DoomerfallAttributes.zs`
  - `AttackKind(inflictor, flags)` returns kind (none / melee / gun), first and second category, gun class. Same order
    of rules as the reference: BFG spray via the exploding ball's tag, Energy splash none, nail puffs stand for their
    shot, a fresh puff/rail hit = the held weapon, a tagged shot = the gun that fired it (even after a switch), an
    untagged projectile = melee only if melee was held when it was fired, everything else none.
  - `AttackFactor`: melee = 1 + Str/100. Gun: x(0.8 + 0.004 Str) if either category is Shotgun, Explosive or
    Automatic; x(1 + (Agi-50) x 0.002) for every gun, x(1 + (Agi-50) x 0.004) when either category is Pistol or
    `DoomerfallRifleTag.IsRifleClass(gun)` (the two Agility parts add, so ±20%). The factors multiply.
  - `LuckyHit`: chance (Luck-50) x 0.1% above 50. A hit with `DMG_EXPLOSION` (one P_RadiusAttack) shares one roll per
    exploding actor per tic (`blastInflictor`, `blastTic`), so a lucky blast crits every target. Burns are dealt with
    `DMG_DD_DEALT`, which skips the source's `GetModifiedDamage` entirely (p_interaction.cpp), so they never roll.
    Luck crits only hits AttackKind traces to the player's weapon (melee or gun), not a barrel the player set off.
- `DoomerfallAgility.zs`: evade code removed (constant, `EvadeChance`, the defensive `ModifyDamage`).
- `manual.md` Attributes: Strength, Agility, Luck lines. In-game help untouched (card 07).
- Daggerfall test component `DoomerfallAttributesTest.cs`: new `-dfattrtest <s> rework` mode cycles Strength, Agility
  and Luck through 8 triples (1 is the lowest; Daggerfall kills a character with a live 0). The old mode now also pins
  Agility and Luck at 50 so card 01's Strength test (pistol as control) stays valid under the new rules.
- Tests: `tools/attributes/attributes_rework.zs` (harness), `attributes_rework_test.py` (fake peer),
  `attributes_rework_paired.py` (paired). `tools/agility/agility_paired.py` now expects zero evasion.

Engineering calls (within the owner's design):
- "Firearm" = any weapon of the player's that is not Melee or Hand-to-Hand (Energy, Precision and Other included).
- "Rifle" = `DoomerfallRifleTag` (the existing rifle tag); "pistol" = category Pistol in either slot.
- One blast = one exploding actor's damage in one tic. If one actor runs A_Explode twice in the same tic, both share
  the roll (rare; DRLA death frames normally run one explode per state).
