## Changes
- `DoomerfallExplosives.zs`: `FromGun` is now `DoomerfallShots.Find(player, inflictor) && skill == Explosives`, chain
  blasts excluded. The handler's own `shots` list, `Tag`, `FiredNow`, `WorldThingSpawned` and `FragmentReach` are gone.
  Side effect: tags are now kept by saves (the shared tag is an inventory item), which closes the earlier "a rocket in
  flight at a save loses its perks" gap. A chain in progress at a save still stops (the queue is not saved).
- Chain blasts no longer set `target`; `RadiusAttack(source, ...)` still credits the kill to the player. With no
  target, `DoomerfallShots.Tag` returns at once, so a blast never becomes a "child" of a nearby tagged rocket (which
  would have given it Explosives' tag and made it count for other perk readers).
- `manual.md`: the "which shots count" line no longer says a rocket that goes off while holding another gun gets
  nothing (that contradicted the next clause); mentions cluster pieces.
- Tests: the point-blank check now looks for the shared tagger's line (`shots: tag ... skill 6 gen 0`); new `switch`
  case.
