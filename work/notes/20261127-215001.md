# weaponvalues 02: rescale Doom gun values; material changes gun weight (run 20261127-215001)

Goal: owner Q&A items 37 and 38 (2026-11-27). Follows weaponvalues 01.

## Plan

1. Values: one factor on every Doom weapon value so a legendary costs 2x its base Daggerfall weapon. Tier
   multipliers are x1/x2/x3/x6/x10, so the factor is 2/10 = 0.2. Kept as a `scale 0.2` line in `WeaponValues.txt`
   (the owner's tier numbers stay readable) rather than rewriting the tiers as 0.2/0.4/0.6/1.2/2.
2. Weights: run each gun's file weight (now its Iron weight) through Daggerfall's own weapon material rule,
   `ItemBuilder.SetItemPropertiesByMaterial` on a scratch item, cached per (weight, material). No copy of the rule.
3. The pickup weight check (`DoomerfallDoomItems.OnTake`) used the class weight before the material was rolled. It
   now creates the item first and checks the item's own weight.
4. Test: the existing paired shop test (`tools/weapon_values/sale_test.py`, `-dfshoptest -dfshopdoomgun`), extended
   to give an Iron and a Daedric RL BFG 9000 and a Daedric BFG Infinity (legendary), and to log Daggerfall's
   Dai-Katana at Iron and Daedric for comparison. Assembled from `review/batch10-stage` into `review/weaponvalues-02`.

## Daggerfall's rules used (from the code)

- Value: `item.value *= 3 * valueMultipliersByMaterial[m]` (Iron..Daedric x1, 2, 4 ... 512) on the template price.
- Weight: `quarterKgs = (int)(kg*4); round(quarterKgs * weightMultipliersByMaterial[m] / 4) / 4`, multipliers
  `{4,5,4,4,3,4,4,2,4,5}` quarters: Iron, Silver, Elven, Mithril, Adamantium, Orcish x1; Steel and Daedric x1.25;
  Dwarven x0.75; Ebony x0.5 (`ItemBuilder.cs:45`, `:659`).

## Values and weights

Generated by `python -I tools/weapon_values/value_table.py [--set Doom] [--all]`, which repeats the game's arithmetic
from `WeaponValues.txt`. One DRLA weapon per (role, tier), then stock Doom. "Base weapon Daedric" is the role's
Daggerfall weapon at Daedric. New Daedric divided by it is 0.2, 0.4, 0.6, 1.2, 2.0 by tier. The factor is the same
at every material, so the ratio holds at Iron too, apart from integer rounding.

Proportions: every value is old x 0.2, rounded to whole gold, at least 1. The only change in proportion is rounding
at the very bottom: Iron pistols (base 3 gold) go 3/6/9/18/30 -> 1/1/2/4/6. Every other entry below is exactly a fifth.
Daggerfall's gold is an integer, so this cannot be exact without changing Daggerfall's item value type.
