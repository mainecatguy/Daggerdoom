# Use on a shopkeeper opens Daggerfall's own shop menu

## Plan

1. Remove the `doomerfallTalkOnly` placeholder in `PlayerActivate.StaticNPCClick`, so Doom's Use on an NPC runs
   Daggerfall's whole static NPC click: guild service menu, merchant menu (Talk / Sell / Exit, or repair, bank),
   tavern menu, coven menu, or plain talk.
2. Check that the Doom menu route survives window chains. `DoomerfallUi` closes Doom's menu only after Daggerfall
   has shown the HUD for 2 frames, so merchant menu -> trade window -> trade question -> trade window, and merchant
   menu -> talk window, stay one Doom menu.
3. Test: a Daggerfall test component (`-dfshoptest`, `DoomerfallShopTest.cs`) that drives each window through its own
   handlers, and a harness (`tools/shop_menu/`) that walks into a general store, Uses a shelf (buy), then Uses the
   shopkeeper twice (sell, then talk).
4. Demo under `review/shop-menu`.

## Design calls

- Buying in a Daggerfall general store is from shelves, not from the merchant menu: the merchant menu's service is
  Sell. Shelf buying already went through Daggerfall's trade window (containers task), so "Buy" here is the shelf.
- Test order is buy first, then sell: the blank test character carries nothing sellable, and seeding items would need
  another test flag. The item sold is the one just bought, which is a fair trade round-trip.
- A Daggerfall general store is a repair shop (`RMBLayout.IsRepairShop`), so its shopkeeper opens
  `DaggerfallMerchantRepairPopupWindow` (Repair / Talk / Sell / Exit), as in Daggerfall.

Ordinary NPC talk and quest offers take the same code path as before: the removed flag only redirected NPCs that
have a service menu. The npc_dialogue harness was not rerun.

## Failed approaches

- Nearest container was a house container (private property), not a shelf: the harness now Uses every container,
  nearest first; the test buys once from the first shop shelf.
- Buying with Select equips the item, and the Sell list hides equipped items. The test buys with Remove.
- The test first bought items a general store does not buy back (Bandage, Parchment). It now buys only weapons,
  clothing, books or jewellery.
- The Sell list shows one tab at a time (Weapons & Armor first), so clothing was missing. The test selects each tab.
