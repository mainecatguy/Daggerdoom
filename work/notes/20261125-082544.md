# Fixed drops: Civil War must be seeded

Branch `agent/fixeddrops-20261125-082544`, continuing `work/notes/20261125-081147.md`. Goal: a Civil War dungeon
plays out the same in every game, whenever and however the player arrives, and each monster drops the same items
whether the player or the other army kills it.

## Plan

1. Find where the war's randomness comes from. Drops were already seeded per monster from its Daggerfall id at death
   (`dd_lootrng.cpp`, previous runs), independent of the killer. What was not seeded: the fight itself. Every living
   monster, its shots and their damage rolls drew from Doom's shared random streams, whose state depends on everything
   else in the game (the player's own ticks, the arrival, other actors). So which monsters died, where and when, differed
   between games.
2. Give the fight its own fixed randomness without changing any odds: each Daggerfall-placed monster ticks under its own
   random state seeded from its Daggerfall id, and each shot or monster it spawns gets a state drawn from it.
3. Test with a new paired harness that lets the war run unfrozen (the old one froze it) and compares fresh games, a
   save and reload mid-war, a run where the player walks and other code burns shared random numbers, and a run where the
   player kills exactly the monsters the other army killed.

## Design

Engine (`UZDoom/src/dd_lootrng.cpp`, small hooks elsewhere, all `[Doomerfall]`):
- `AActor::ddAiRng`: the live random state. `DThinker::CallTick` runs every thinker's tick under it when it is set
  (`DD_AiStateFor`, one line in `dthinker.cpp`). Outside a bridge session `DD_AiStateFor` returns null at once, so stock
  games and plain WADs never use it.
- A living monster with a Daggerfall id gets it the first time it ticks, seeded from the id alone (salt `SALT_LIVE`).
  Saved with the actor (`ddairng`).
- A missile or monster spawned while such a state runs (a shot, a Lost Soul) gets its own state, one step of the
  running one (`DD_LootInherit`). So a shot's flight, its hit and its damage roll are fixed too. Puffs, blood and other
  helpers already got a loot state there, unchanged.
- When a monster starts dying (`DD_LootDied`) the live state is cleared, so its corpse ticks as before and nothing it did
  while alive reaches its loot, which keeps coming from its id alone. `Revive` clears both.
- The odds, the AI and every random call are untouched; only the stream each draw comes from changes.

War time: the war starts when Daggerfall's facts reach Doom and the mooks are spawned, so it runs relative to that tic,
not to Daggerfall's clock or the player's arrival. Doom reads no Daggerfall time for a dungeon fight.
