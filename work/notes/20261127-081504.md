# The Uzi is an Automatic (20261127-081504)

Goal: DRLA's Uzi (and its variants) counts as an Automatic, not a Pistol, in the weapon's Type line, the Daggerfall
inventory, and for the Automatics perks. Owner, 2026-11-27: "It's an Automatic. That's miscategorized."

## Plan

1. Find why the Uzi is a Pistol: `BothWithTokens` returns Pistol for any gun with DRLA's pistol token before anything
   else, and the Uzi has both the pistol and the rapid-fire token.
2. Check every DRLA pistol-token gun for automatic fire.
3. Add the Uzi family to the owner's Automatics list (`IsOwnerAutomatic`) and let that list override the pistol token.
4. Update the tests that encoded "Uzi = Pistol" and the manual; run the weapon types and weapon category tests.
5. Demo.

## Change

`mods/doomerfall/src/zscript/DoomerfallWeaponCategory.zs`: `IsOwnerAutomatic` is now a list that adds the eight Uzi
classes, and the Pistol rule skips guns on it:
`if (w is "Pistol" || ((tokens & TokPistol) && !IsOwnerAutomatic(w))) return Pistol, ...`.
An Uzi then follows the usual order (Explosive > Energy > Shotgun > Precision > Automatic) and lands on Automatic.
The cell-fed **Plasma Uzi is not on the list and stays Pistol + Energy**, as before this card. Taken off the Pistol
rule, it would land on Energy only, because Energy comes before Automatic and the owner's two-skill pairs are only
Pistol+Energy and Shotgun+Energy. That would neither make it an Automatic nor keep its old behaviour, so it is a
design choice for the owner (question below). (Revision: my first pass made it Energy only, and the verifier rejected
that. Reverted.)

The Type line (Doom's `DoomerfallWeaponTypes` -> `BothOfClass`), the Daggerfall inventory description (it shows what
Doom sends), and the skill/perk code (`SkillSlotOf` -> `Both`) all use `BothWithTokens`, so this one rule covers all
three. No engine change and no C# change.

## DRLA pistol-token guns checked

Method: DRLA's own tokens (`DoomerfallWeaponTokens`, derived from DRLA's DECORATE), plus a trace of each gun's Fire
state with the trigger held, using `tools/rifle_tag/derive_rifles.py`'s `trace_fire` (scratch script, not committed).
"gap" is the closest two shots in tics. The DRLA Pistol itself re-fires when held (14 tics a shot), so "re-fires when
held" alone does not mark an automatic. I used DRLA's rapid-fire token, the fire rate, and the gun's name.
