# Daggerfall menu text at full resolution: verification (run 20261127-082629)

Continues `work/notes/20261127-061016.md` (the fix, the 320x200 audit, failed approaches). That run resized
Daggerfall's UI window to Doom's screen on each menu open and ran out of budget before verifying it.

## Plan

1. Surface cap: owner (2026-11-27) "1920x1080 is fine as a max resolution". Keep `DFB_SURFACE_MAX_W/H` at 1920x1200;
   no change. Bigger Doom screens get a surface scaled down to fit (keeping aspect: 2560x1440 -> 1920x1080, 4K -> 1920x1080)
   and Doom upscales it.
2. Verify in a paired run: inventory item info, character sheet, shop, talk.
3. Side-by-side with Daggerfall Unity at the same window size.

## Result

Run: `python tools/menu_text/menu_text.py review\menu-text review\menu-text-runs\verify --size 1920x1080 --menutext --hover --timeout 60`
(the private desktop gave Doom a 1892x1001 client area).

df.log: `ui: window 1920x1080 resized to 1892x1001 for Doom's 1892x1001 screen`, `ui: surface 1892x1001 for a 1892x1001 window`.
No fatal errors in either log.

| Window | Doom screenshot vs Daggerfall Unity's render, mean abs difference per channel (0-255) |
|---|---|
| Inventory, item info (Casual Pants, Condition: New, Worth: 5 gold, Weight: 0.50 kg) | 0.06 |
| Character sheet | 0.11 |
| Shop (trade window, same item info) | 0.07 |
| Talk window | 0.01 |

The surface equals Doom's screen, so Doom draws Daggerfall Unity's pixels 1:1: the text is exactly as sharp as
Daggerfall Unity renders it at that window size, and the art (label art such as "LEVEL:", stone, paper doll) keeps its
classic 320x200 look. The small differences are the anti-aliased edges after Doom's colour pass, nothing visible.

## Known gaps

- The Daggerfall Unity side is Daggerfall Unity's own render inside the paired session, not a separate standalone
  Daggerfall Unity process: standalone captures came out black on quiet_run's private desktop (previous run, three
  ways). It is the same UI code drawing at the same size; a standalone side-by-side by eye is on the play-test list.
- Screens above 1920x1200 are upscaled by Doom (owner: 1920x1080 max is fine).
- Resizing Doom while a menu is open: Daggerfall keeps the size from the open until the next menu open.
- Talk was shown without an NPC (empty topic list, "Regional" heading only); the dialogue text uses the same TextLabel path.
