# Animated textures and ordinary dungeon flats

## What was added
- **Ordinary billboards.** `tools/dungeon_converter/FlatExport.cs` exports flats without actions to a `DFDFLATS` lump. `DFDungeonFlat` actors draw them with no collision, as Daggerfall Unity does. Size follows `MeshReader.GetBillboardMesh`, and the picture is centered on the position.
- **Animated textures.** Every frame is exported and driven by ANIMDEFS. Rates come from Daggerfall Unity: light billboards 12 fps, other billboards 5 fps, model textures 12 fps, fire walls (archive 356) 5 fps.
- **Engine change.** `hw_dfmesh.cpp` keeps a texture ID per batch and asks for the current animation frame when drawing. It only runs on maps with a DFMESH lump.
- **Action flats** use the same textures, so they animate and have Daggerfall's size. The old limit of 26 distinct action flats is gone.
- **Tools.** `--list-flats` ranks dungeons by flat count. `flat_check.py` measures frame cost and captures animation. `action_regress.py --exe <path>` tests a private build.

## Flats intentionally not drawn
- **Archive 199, editor markers.** Daggerfall Unity hides these too. Their action records still run.
- **Archive 216, fixed treasure, and NPC archives (RDBLayout.NPCFlatArchives).** Daggerfall draws them, but loot and talking do not work on them here, so drawing them would promise something false. If one has a moving or chained action, it is still drawn so a working switch can be found.
- Counts not drawn: Scourg Barrow 244 editor and 7 NPC. Privateer's Hold 56 editor. Orsinium 224 editor, 20 treasure, 1 NPC.

## Results
| Dungeon | Ordinary flats | Outside a Doom sector at their height |
|---|---|---|
| Orsinium (most of 4,232 dungeons; median 187) | 487 | 8 |
| Scourg Barrow | 426 | 3 |
| Privateer's Hold | 129 | not read from the log |

- **Frame cost: no measurable cost.** Orsinium, densest reachable node (57 of 487 billboards within 512 units), uncapped, vsync off, Vulkan, RTX 5080, 1252x641 off-screen window, 350 tics per run, `dfmesh_bench`. Median frame with flats 2.19 and 2.57 ms, without flats 2.44 and 2.11 ms. The difference between the averages (about 0.1 ms) is smaller than the spread between identical runs (0.33 to 0.38 ms). This view is one location, and it does not show how many of the 57 were on screen.
- **Animation on screen.** Scourg Barrow fireplace: 4 different images in 4 shots. Torches in Scourg Barrow and Privateer's Hold: 3 different images in 4 shots, repeating as a loop would.
- **Regressions** (`action_regress.py`, private build): stock E1M1, E1M1 with DRLA, E1M1 beside the package, all 58 Privateer's Hold doors, player and Imp door bodies, Scourg Barrow save and load all pass.
- **Enemies on:** the Scourg Barrow demo packages ran for the 30 second limit with no script error. Enemy behavior was not tested.

## Failed approaches and traps
- The first bench was capped at 35 fps by `cl_capfps 1`, so its 28.5 ms was meaningless. It was rerun uncapped.
- Without `_player.pk3`, door 15 in Privateer's Hold fails the walk test. With the player package it passes. The regression must use a `--daggerfall-player` conversion.

## Not verified or not done
- **`play.bat` has not been run.** The permission system blocked copying the engine into the review folder, so the script copies the engine and both audio DLLs on its first run.
- Water was not specifically rechecked. No water code changed.
- `--runtime-dungeon` packages were not tested. ANIMDEFS is read at startup, so a package mounted later may show only frame 0.
- Texture packs: the exporter still reads Daggerfall's archive and record, so a later pack can follow them. Pack support itself is a separate item.

## Play-test list
1. Run `D:\dev\DoomDaggerfall-loop\review\dungeon-flats\play.bat`. Check torches flicker at a natural speed and sit on their brackets.
2. Find the fireplace and blue shard in Scourg Barrow and check they animate.
3. Look for flats that pop in or vanish around corners. Sprites depend on Doom sector visibility, while the mesh does not.
4. Run `play.bat holds` and check the entrance area, doors, and plants.
