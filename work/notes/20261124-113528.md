# Load Daggerfall saves that have no Doom data (20261124-113528)

## How it works
1. Entry point: Doom's console command `dd_load_daggerfall` (at Doom's title, `-dfflow` only) asks Daggerfall to show
   its own Load window inside Doom (new UI id `DFB_UI_LOAD_GAME` = 8), as character creation is shown. A save loaded
   there is a "plain load": Daggerfall state with no Doom half. The bundled load (`DoomerfallSave.RunLoad`) is a separate
   path and is untouched. There is no Doom menu entry yet (see questions).
2. `DoomerfallPlainLoad.cs` arms when the chosen save starts loading while that window is open, then holds the loaded
   game (paused, position sync off via `LoadRunning`) and sends `DFB_KIND_PLAIN_LOAD` (210, `dfb_plain_load`): exact
   world position and facing outdoors; dungeon map id plus the player's dungeon-space position in a dungeon; the
   building's door (world units) plus the building-space position in a building.
3. Doom (`dd_bridge.cpp`) runs the New Game chain with `ngPlain` set: difficulty prompt, the same fixed default class as
   New Game (`PlayerClasses[0]`), DDOVER01, travel, then the dungeon door (`DDTreadmill_RequestDungeon` with a start
   point) or the nearest building door within 256 units (`DDTreadmill_RequestBuilding`, new). Before arriving it sends
   `DFB_KIND_STARTER` (211): the loaded pistol's pickup class (`RLPistolPickup` with DRLA, else `Pistol`), its weapon
   slot, and the class's start amount of its reserve ammo (`Player.StartItem`, or, when the class gives ammo by script
   as DRLA X does, the count Doom holds while still frozen at the start).
4. Daggerfall answers `NEWGAME_GO` without restarting quests or the clock, and `DoomerfallHotkeys.BeginPlainStart`
   applies the owner's weapon rules: Doom puts away every gun (fist only, `DFB_GUN_CLEAR`); then Daggerfall draws the
   first Doom gun by hotkey order (keys 1-9, then 0; squares in order), else the first Doom gun in the inventory. With
   none, it adds the starter pistol and Regular (Iron material) bullets of the start amount as real inventory items,
   puts the pistol on its weapon slot key if that key has no hotkeys (the existing auto-hotkey rule), and draws it.
5. Ammo: `DoomerfallAmmo.PreferDaggerfall` makes Daggerfall's stacks set Doom's counters on a plain load. Without it,
   Doom's new game class ammo (40 bullets, 5 shells with DRLA X) would be mirrored into, or remove, the save's stacks.

Other changes: `dd_treadmill.cpp/.h` dungeon start point copied byte for byte from `overnight/newstart` (not merged yet)
so that merge is clean; building start point added beside it. Bridge kinds 210-211 (above `locationledger`'s
reserved 200-209). Logs: Doom items are listed in Daggerfall's save line, hotkey load line, and plain load arrival line.

## Failed approaches / notes
- Arming on the window's close was too late: the load finished before the window's two HUD frames, so it now arms on
  Daggerfall's load start while the window is still open (the close check stays as a fallback).
- First starter ammo was 0: DRLA X's player class lists no `Clip` start item. Now it falls back to the held count.
- D: was nearly full (65-220 MB free, filled by other lanes), so Unity player builds failed with "Failed to write file".
  The worktree's `daggerfall-unity-master/Temp` and `Builds` are junctions to this session's scratchpad on C: (both are
  git-ignored). If the scratchpad is cleared, delete the two junctions and build normally.
- Daggerfall's own enemies saved in a plain save are restored hidden in Daggerfall (AI off); Doom's converted map supplies
  its own monsters. Not changed.
- The Unity build rewrites the tracked `addressables_content_state.bin`; left uncommitted.

## Play-test list
- Type `dd_load_daggerfall` in Doom's console at the title: Daggerfall's Load window appears, readable and usable with
  mouse and keys. Cancel returns to the title.
- Load a save from inside a dungeon: you stand where the save had you, facing the same way.
- Load a save made outdoors in a town and one made inside a shop or house: same place, inside the same building.
- A character with no Doom guns: you briefly hold the fist, then the pistol comes up; inventory shows the pistol and
  40 Regular bullets; key 2 draws the pistol.
- A character with Doom guns: that gun comes up; no extra pistol or ammo.
- Save, load the bundled save: nothing doubled.
