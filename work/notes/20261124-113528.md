# Load Daggerfall saves that have no Doom data (20261124-113528)

## Plan
1. Entry point: Doom asks Daggerfall to show its own Load window inside Doom (new UI id `DFB_UI_LOAD_GAME`), from the
   title, like character creation. A save loaded from that window is a "plain load": Daggerfall state with no Doom half.
   The bundled load (`DoomerfallSave.RunLoad`) is a different path and is not touched.
2. Daggerfall holds the loaded game (paused, position sync off) and sends Doom where the player is
   (`DFB_KIND_PLAIN_LOAD`): exact world position outdoors; dungeon map id and dungeon-space position in a dungeon;
   the building door and building-space position in a building.
3. Doom reuses the New Game chain: difficulty prompt, default class (`PlayerClasses[0]`, same as New Game), DDOVER01,
   travel, then the door (dungeon or building) with the saved start point. It sends the starter gun facts
   (`DFB_KIND_STARTER`: pistol pickup class, its weapon slot, the class's start amount of its ammo), then
   `NEWGAME_ARRIVED`; Daggerfall answers `NEWGAME_GO` without restarting quests or the clock.
4. Starting weapon (owner's rules): Doom is stripped to its fist (`DFB_GUN_CLEAR`). Then Daggerfall draws the first
   Doom gun by hotkey order (keys 1-9, 0; squares in order), else the first Doom gun in the inventory. With none, it adds
   the starter pistol (DRLA `RLPistolPickup` or stock `Pistol`) and Regular (Iron) bullets of the class's start amount,
   hotkeys the pistol on its weapon slot key by the existing auto-hotkey rule, and draws it.
5. Ammo: on a plain load Daggerfall's stacks win over Doom's counter (Doom's new-game class ammo would otherwise be
   mirrored into, or remove, Daggerfall's stacks).

## Decisions and notes
- Bridge numbers: kinds 210-212 (above `locationledger`'s reserved 200-209), UI id 8.
- `dd_treadmill.cpp/.h`: the dungeon start point code is taken byte for byte from `overnight/newstart`
  (not merged yet), so the later merge is clean. A building start point is added beside it.
- Entry point in Doom's menus: a console command `dd_load_daggerfall` for now (see questions).
