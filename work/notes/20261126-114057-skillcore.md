  that store "Orcish" still load. .NET's `ToString()` then prints the alias (`perktest: Orcish set to 20`, the

  save converter. Not fixed; a custom serializer for the enum would be the clean fix if it ever matters.
- Un-held DRLA guns are categorised by ammo only (see the earlier notes).
