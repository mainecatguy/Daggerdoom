## Findings

- **Which dungeons have NPCs.** `DungeonConverter --list-flats` now also prints `NPCFLATS <count> #<map id> <name>` for
  every dungeon whose blocks hold NPC flats (the archives `RDBLayout` turns into static NPCs). Only 8 of 4232 dungeons
  have any: Sentinel 27, Wayrest 24, Daggerfall 21 (the royal castles), Scourg Barrow 7, Mantellan Crux 3, Direnni
  Tower, Shedungent and Orsinium 1 each. Daggerfall city is runtime group 9183 (`ddruntime.groups.tsv`).
- **The harness missed dungeon NPCs.** Earlier notes said dungeon NPCs are `DFNpc` actors. That was wrong: they are
  `DFDungeonNpc` (`tools/dungeon_converter/action_objects.zs:40`, spawned at line 435). The harness followed only `DFNpc`,
  so the first Castle Daggerfall run reported `npcs 0`. `harness.zs` now follows both classes, looked up by name at run
  time so a missing class is skipped.
- No change to the game code. Daggerfall never sends a dungeon NPC list (`DD_NpcsFrame` asks only in interiors), so the
  clock does not move dungeon NPCs. The hold runs for one tic there ("no townsfolk list"), and the runs confirm nothing
  moves or blinks.
