# New Game through Daggerfall's real menus

## Result

A player starts at Doom's title, chooses New Game, makes a character in Daggerfall's real wizard inside the Doom window, watches the cinematics, picks a Doom difficulty, and arrives inside Privateer's Hold with both games running.

Demo: `D:\dev\DoomDaggerfall-loop\review\new-game\play.bat`. It has not been launched by double click, because that would take focus. The automated runs use the same launcher, builds, data, and flow flags, minimized.

## How it works

1. `-dfflow` on both games. Without it, none of this runs.
2. Doom's New Game menu entry opens `DFB_UI_NEW_GAME`. Daggerfall waits behind the title with no game.
3. `StartNewCharacter` places the character, then stops before the clock, main quests, and start events.
4. Doom asks for a difficulty, using the first player class. Both are the owner's temporary choice.
5. Doom loads the overworld behind a black screen, travels to the start pixel, and enters through the location's real dungeon door, so the exit door and save data work normally.
6. Doom reports arrival. Daggerfall starts its clock and quests, then both run.

Each New Game gets a campaign ID in the save manifest. Auto and quick slots use it, and Load Last Save only considers that character's saves. Older bundles have no ID and keep the old names.

`dd_treadmill.cpp` got one small addition (`DDTreadmill_RequestDungeon`), because Doom had no way to enter a dungeon except by the player using the door. The parallel lane edits this file, so expect a possible small merge.

Command: `python tools/new_game/run_new_game.py <mode>`. Input is real window messages to Doom, except that the New Game entry and difficulty are selected through Doom's menu code.

## Failed approaches and bugs found

- A second character could not start, because Daggerfall reported "boot" after leaving a game. It now reports "menu" in a flow session.
- The driver's early click positions were wrong for centered panels and for the skill screen's left and right arrows.

## Input not forwarded to Daggerfall's menus

- Gamepad input.
- Key auto-repeat, because Daggerfall tracks held keys itself.
- Alt+F4 and Alt+Enter stay with Doom on purpose.

## Known gaps

- Quicksave is not bundled with Daggerfall's state yet. Quick keys were out of scope.
- First-run Daggerfall setup is not shown through Doom. The launch needs a valid Daggerfall folder.
- New Game during a running game is refused with a message. End Game first.
- Cinematic sound has not been checked.
- Doom's Options > End Game was changed to return both games to the title, but no automated run used it. The death screen's Main Menu shares the same code and passed.

## Play-test list

1. Double-click `play.bat`. Use the keyboard and mouse to choose New Game from Doom's real menu.
2. Make a character, including typing a name and using the class questions.
3. Watch all three cinematics and check picture, sound, and skipping with Esc.
4. Press Esc at the difficulty prompt. It should come back, because a difficulty is required.
5. Confirm the arrival spot and facing feel right, and walk out of Privateer's Hold.
6. Save, die, use Load Last Save, then End Game and make a second character.
