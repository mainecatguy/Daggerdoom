# Rest in Doom (20261126-113251)

Goal: a Doom key opens Daggerfall's rest window; resting works as in Daggerfall (time, vitals, skill and level-up
check) with HP restored at 3x; refused with Doom monsters nearby; a level-up shows "You have reached level N" on Doom's HUD.

## Plan

1. Doom: `netevent df_rest` (Doomerfall Controls "Rest", demo binds B; R is Doom/DRLA reload) opens a new menu
   `DFB_UI_REST` like the journal and inventory. With the request Doom sends what only it can know (Doom owns the world
   and movement): `DFB_REST_MONSTERS_NEAR` and `DFB_REST_NOT_GROUNDED`.
2. Daggerfall: the menu posts Daggerfall's own `dfuiOpenRestWindow`, so every Daggerfall refusal and message runs as
   in Daggerfall. Two one-line hooks feed Doom's facts into Daggerfall's checks: `GameManager.AreEnemiesNearby(resting)`
   and the swimming/grounded check in `DaggerfallUI`'s rest message.
3. 3x HP: `FormulaHelper.CalculateHealthRecoveryRate` times `DoomerfallHealthRecoveryScale` (3 in a bridge session,
   1 otherwise), the same pattern as `DoomerfallMaterialRoll`.
4. Level-up line: the character sheet calls `DoomerfallRest.LevelReached(level)` where it raises the level; Daggerfall
   sends a new `DFB_KIND_HUD_TEXT`; Doom holds it until Daggerfall's menu closes (Doom draws no HUD over a menu, and the
   HUD text timer would expire the line unseen), then shows it as Daggerfall HUD text.
5. Test hook `DoomerfallRestTest.cs` (`-dfresttest <file> [level]`), harness `tools/rest/rest.py`, demo
   `review/rest/play.bat`, manual section.

## Findings

- Daggerfall's monster rule (`GameManager.AreEnemiesNearby(resting: true)`): an enemy blocks rest if it targets the
  player and sees them, or is within 12 m (when it is also close enough that classic would have spawned it). Doom's
  version (`RestState` in `dd_bridge.cpp`): live, non-friendly `ISMONSTER` actors (DRLA's hungry spawner excluded) that
  target the player and pass `P_CheckSight`, or are within 12 m = 900 Doom units (75 units per metre, as `dd_lights.cpp`).
  Guard bots count when hostile, as Daggerfall's spawned guards do (this matches the open question's lean).
- Doom is paused behind any Daggerfall menu, so monsters cannot approach during the rest; the flag taken at the key
  press stays valid for Daggerfall's hourly re-check. Daggerfall's own random encounters are off in a bridge session
  (`PreventEnemySpawns`), so nothing interrupts a rest yet. "Interrupted by Doom ambush packs" (gamedesign.md) is not
  part of this card.
- Daggerfall's skill check at the end of a rest only runs if 6 game hours passed since the last one; a short rest may
  not level you up. That is Daggerfall's rule, kept.
- Daggerfall's town rules apply unchanged: resting outdoors inside a town is Vagrancy and spawns guards (Doom guard
  bots in Doomerfall); indoors needs a rented room, own house or guild hall.
- The exhausted-collapse rest (`PlayerEntity`, fatigue 0) also uses the health recovery formula, so it is 3x too. That
  fits "all sources of HP restoration are 3x". Potions, spells and Doom pickups are not changed by this card.
- Doom's rest key pressed again while the rest window is open closes it through `PopToHUD` (as every Daggerfall menu
  in Doom): mid-rest that stops the rest without Daggerfall's wake-up message or end-of-rest skill check. Daggerfall's
  own Stop button and Escape end it normally.
