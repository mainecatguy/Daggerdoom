Run 20261124-215049, branch agent/expandedinv-20261124-215049. Continues `work/notes/20261124-214741.md`.

## What the mod is (from the bundle)

`expanded inventory.dfmod` (v1, by Alex Falconson, AlikFalcon, LechatSokolov) holds one compiled assembly, a string
CSV and 10 pictures. Its code (about 3,000 lines decompiled):

- `ExpandedInventoryWindow : DaggerfallInventoryWindow`, registered for `UIWindowType.Inventory`. Seven tabs (Weapons,
  Armor, Jewellery, Magic, Ingredients, Reading, Clothing & Misc) plus "All", two filter drop-downs (material / type),
  gold on the left, wagon and ground buttons, an animated magic eye.
- `CustomItemScroller : ItemListScroller`, lists of 3 columns x 6 rows, each with its own scroll bar on its right.
- `DropdownList`, the filter popup. `ExpandedInfoBridge`, an optional reflection link to the "Expanded Info" mod.
- It replaces only the inventory window (containers, ground, wagon). **Shops use Daggerfall's trade window, which this
  mod does not replace** (question below).

## How it is built now

- **Code:** `daggerfall-unity-master/Assets/Scripts/ExpandedInventory/`, compiled into Daggerfall Unity by CliBuild,
  so `scripts/play/install.py` puts it in the play folder with the rest of the build. Decompiled with
  `tools/expanded_inventory/extract.py` (ilspycmd, C# 7.3, DFU's Managed folder as references, so it is clean C#).
  Changes from the mod are marked `Doomerfall` in the files:
  - `ExpandedInventory.cs`: registers the window at `AfterSceneLoad` (the mod did it from its mod Init). Registers only
    when the pictures are installed; otherwise logs one line and keeps Daggerfall's window.
  - `ExpandedInventoryArt.cs`: loads the pictures from `StreamingAssets/ExpandedInventory/*.png`, the mod's strings
    (was its CSV), and the layout constants. `Background()` rebuilds the list area of the background (both the plain
    and highlighted copies) in the 4 and 2 layout by copying pixel columns at runtime, so no edited picture exists.
  - `CustomItemScroller.cs`: the column count is a constructor argument (4 left, 2 right); the panel now has a real
    position and size (the mod left it zero-sized, so `MouseOverComponent` was never true and Doomerfall's
    number-key-over-an-item hotkey check could not fire).
  - `ExpandedInventoryWindow.cs`: list rects from `ExpandedInventoryArt`; pictures from it; Doom guns and ammo listed on
    Weapons, Doom armor on Armor, never on Clothing & Misc (`ExpandedInventoryDoom.cs`, from
    `DoomerfallDoomItem.InWeaponsAndArmorTab`); the Expanded Info link removed (that mod is not installed).
  - `ExpandedInfoBridge.cs` dropped.
- **Pictures:** they are edits of Daggerfall's inventory art, so game data: never committed. `install.py` copies them
  from `GameMods\ExpandedInventory\Textures`, or extracts them from the download (`.zip`) in `GameMods\ExpandedInventory`,
  or from `--expanded-inventory <zip or folder>`. Agents cannot write to GameMods, so **the owner should copy the zip
  to `D:\dev\DoomDaggerfall\GameMods\ExpandedInventory\`** (or pass `--expanded-inventory`). Without them the game
  falls back to Daggerfall's own inventory window.

## Layout

Native pixels. The mod: left cells 162-230, left scroll bar 232-240, right cells 241-309, right scroll bar 311-319.
Now: left 4 cells 162-253, the left list's scroll bar 255-263 between the lists, right 2 cells 264-309, right list's
scroll bar 311-319 at the edge (each list keeps its own scroll bar, as in the mod). Judgment call: "the scroll bar sits
between the two lists" read as the left list's bar; the right list's bar stays at the edge.

## Doomerfall hooks kept

The window derives from the stock window, so `DoomerfallHotkeys.InventoryUpdate` (Update), `BlockEquip`
(EquipItem), `TransferItem`, `ItemHelper` custom icons and info (`ICustomItemImage`, `ICustomItemInfo`) all still run.
The mod's click handlers match the stock ones line for line (checked), except right-click always moves the item.

## Tests

- `-dfexpinvtest <dir>` (`ExpandedInventoryTest.cs`, starts itself, no hook in game classes): in a bridge session,
  opens the real inventory window, logs class, columns and positions, the tab of each Doom item, moves bullets and one
  Daggerfall item across and back with the window's own handler, saves screenshots, checks ammo counts, logs PASS/FAIL
  (`expinv:` lines in the Daggerfall bridge log).
- `tools/expanded_inventory/assemble.py <source review folder> <target> <pictures or zip>` makes the test/demo folder.
