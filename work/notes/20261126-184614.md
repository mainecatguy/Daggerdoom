  It works through the existing `only=1` rule (classes instead of kinds), so no planner code changed. The `Humanoid` row is

### Engineering and judgment calls

- **Castles count as holding armies.** Entering a city's dungeon (the palace) plans an army like any dungeon
  (`DoomerfallMonsters.BuildPlacements` runs for every dungeon), so the table's "only if they hold armies" applies, and
  they got 3/14/14 and Humanoid. **Side effect, small:** outside the palace, drops and ammo use the terrain
  level (`DoomerfallAreaLevels.ForCurrentPlace`; `DoomerfallAmmo.AnswerLevels` uses the dungeon level only for dungeon
  keys), so they do not change. The one city-wide effect is the travel hint's danger word, which reads `Level.Area`
  (`DoomerfallTravelHint.cs:48`): the cities of Daggerfall (7 to 3), Wayrest (16 to 14) and Sentinel (25 to 14).
  (An earlier version of these notes wrongly said drops and ammo change too; a verifier caught it.)
- **What "plain" means in DRLA.** Exact classes only: the stock Zombieman, ShotgunGuy and ChaingunGuy, and DRLA's base
  classes for them, RLFormerHumanPistol, RLFormerSergeantShotgun and RLFormerCommandoChaingun (DRLA's base chaingunner;
  `RLStealthChaingunguy` inherits from it). Left out: DRLA's weapon variants (RLFormerHumanBattleRifle 1-3,
  RLFormerSergeantCombatShotgun, RLFormerCommandoBattleRifle, which DRLA's spawners list as alternatives to the base
  classes), all RLElite*, RLStealth*, RLFormerCyborg*, RLFormerCaptainPlasmaRifle, the Armageddon troopers and Colourful
  Hell recolours. The first version admitted the weapon variants through wildcards; a verifier rejected that, and the
  weapon variants now wait on the owner (question below).
- **More bodies.** Plain Former Humans are cheaper, so the same level 1 budget (pool 14700) buys more: 95 escorts (mooks)
  instead of 73 under the old Humanoid theme. The budget rule itself is unchanged. Worth a play test.
- One table in C# rather than a data file: the levels must also match `area_level.py`, and the runtime dump check below
  catches any drift between the two.
