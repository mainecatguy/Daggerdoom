# Hotkeys menu drawn like Daggerfall's inventory (20261124-071038)

Goal: the owner asked (2026-11-24) that the Doom weapon hotkeys popup look like a Daggerfall inventory menu.
Only the look changes. The hotkey logic in `DoomerfallHotkeys.cs` is untouched apart from a test-only hook.

## Plan
1. Add a standalone screenshot test (`-dfhotkeyshots <dir>`) that opens the real inventory with the real popup on top.
2. Build Daggerfall Unity with the old popup, capture it.
3. Restyle `DoomerfallHotkeyPopup.cs` using only pictures cut at runtime from Daggerfall's own inventory files.
4. Build again, capture the new popup, compare.
5. Assemble a playable review folder with `scripts/play/install.py`.

## Design (engineering calls inside the owner's request)
Everything is cut at runtime from `INVE00I0.IMG` (and `INVE01I0.IMG` for the highlighted button), the same
files and the same `ImageReader.GetSubTexture` approach `DaggerfallInventoryWindow` and `ItemListScroller` use.
Nothing derived from game data is committed.

| Old | New |
|---|---|
| Black, 85% opaque box | Inventory stone (cut from inside the paper doll frame, mirrored to fill), dark outline, bevel lit from the top left, bevelled line under the title, the inventory's own edge colours |
| Five grey 28x28 squares | Five 50x38 item slots cut from the inventory's item lists (four from the player's list, one from the other list, so they differ the way the inventory's do) |
| Icons stretched to fill the square | Icons drawn as the inventory draws them: native size, shrunk only to fit, centred, 2 px margin |
| Small red "x" in each square's corner | Daggerfall's own REMOVE button under each filled slot, turning gold on hover (from `INVE01I0.IMG`) |
| White text | The inventory's yellow text with its shadow, upper case labels (`3 (1)`, `CTRL+3`, `ALT+3`) |
| — | Tooltip with the item's long name over a filled slot, as in the inventory |

Behaviour is the same: click a slot to assign the hovered item, REMOVE clears it, a used-up consumable shows a grey X,
the number key or a click outside closes the popup, Escape cancels.

## Findings / failed approaches
- `BackgroundLayout.Tile` tiles in screen pixels, not native pixels (`BaseScreenComponent.cs:795`), so at 1280x800 a
  tiled stone would be drawn at a quarter of the inventory's scale. The panel background is instead built once at
  native size and stretched.
- Doom item art comes from Doom over the bridge, so the standalone screenshot test fills the slots with Daggerfall
  items (ebony mace, potion, steel cuirass, and a dagger that is then removed to show a used-up slot).
