# Automatics perks (skillperks 02), run 20261126-222743

## Plan

1. Daggerfall decides the Automatics rules from the live skill and sends them in the character sheet, the way the
   climbing chances already travel (Daggerfall owns rules, Doom applies them).
2. Doom applies them in ZScript to the held gun when its skill is Automatics (`DoomerfallWeaponCategory.SkillSlotOf`),
   so the stock Chaingun and DRLA rapid-fire guns both work.
3. Test against a fake Daggerfall peer (exact rule sets, stock and DRLA), then a paired run with real Daggerfall stepping
   the skill 20, 26, 50, 75, 100.
4. Perk text, manual, notes.

## What was built

- **Bridge:** sheet format 7, `DFB_SHEET_INTS` 162, new `DFB_SHEET_AUTO_*` (155-161): damage bp; burst bp, shots and
  reset ms ("+x% on the first n shots", as the card asks); shots per ammo; sunder bp per hit and cap. Generated
  bindings refreshed (`bridge/generate_bindings.py`).
- **Daggerfall:** `DoomerfallAutomaticsRules.cs` holds the owner's numbers and fills the sheet (`DoomerfallSheet.Fill`,
  one line). Perk texts for 25/50/75/100 are marked built; 75 got its text.
- **Engine (UZDoom):** one native, `Actor.DD_SheetValue(index)`, next to `DD_SheetSkill`. Returns -1 with no bridge
  character, so stock Doom and Doom-only games see nothing.
- **Doom mod:** `mods/doomerfall/src/zscript/DoomerfallAutomatics.zs`. A holder item on the player (only while a
  Daggerfall character is loaded) counts shots, refunds saved ammo and adds the damage bonuses; `DoomerfallSunder` on
  an enemy adds the +1%-per-hit damage taken. `dd_perklog` (logging only) lifts the 200-line log cap for tests.

## Engineering calls (within the owner's rules)

- **Live skill** decides, as the gun's skill choice already does, so a drained or fortified skill counts.
- **Damage scaling is linear**: +0.6% per skill point, +60% at 100 and above.
- **A shot** is a tic in which the gun spent ammo with the trigger down (or hit something with it down). Bullets in one
  tic are one shot. The burst restarts when the gap since the last shot is over 0.3 s (10 tics).
- **Burst and skill bonus multiply** with each other and with Daggerfall's material bonus (gamedesign/damage.md: bonuses
  multiply).
- **Ammo saving** refunds to the ammo the gun fires from (AmmoType1): the stock reserve (then reported to Daggerfall as
  usual, Doom owns live ammo) or DRLA's magazine. The first shot of each group pays. Drops with the trigger up (a
  change-ammo unload) are ignored, so an unload never duplicates rounds.
- **Sunder** counts every bullet that hits (per hit), applies after the hit (a hit does not boost itself), stays on the
  enemy for good and is kept by Doom saves. A later lower cap never removes stacks.
- **Rounding**: fractional damage rounds up with the chance of the fraction, so +1% on a 5-point bullet is worth +1% on
  average instead of nothing.

## Tests

Builds (lane-private, `D:\dev\DoomDaggerfall-build\autoperks\`): UZDoom, bridge DLL, launcher; Unity
`CliBuild result: Succeeded`.

- **Fake-peer test** `tools/automatics/automatics_test.py` (wrapped in quiet_run): **185 of 185 checks passed**. DOOM.WAD
  E1M1, stock (`Chaingun`) and the play_drlax DRLA set (`Chaingun`, `RLChaingun`, `RLBattleRifle`, `RLUzi`,
  `RLMinigun`), rule sets off / dmg / burst / ammo2 / ammo4 / sunder / full, plus a run with no bridge. Checks every

  not a short one, ammo per shot, the sunder probe (115 after 15+ hits, 100 on a fresh target), and no perk activity
  without a Daggerfall character. The Uzi reads Pistol (slot 7) and gets nothing.
- **Paired run** `tools/automatics/automatics_paired.py` (real Daggerfall + Doom through the launcher, DDOVER01, DRLA):
  **PASS**. Daggerfall stepped Automatics 20, 26, 50, 75, 100 (4 perk windows opened and were clicked shut); in each
  whole cycle Doom read exactly the rules `DoomerfallAutomaticsRules` gives for that skill, every hit carried the right
  factor, ammo per pull went 2 -> 1 (50) -> ~0.5 (100), the probe showed sunder from 75. Result in
  `D:\dev\DoomDaggerfall-loop\review\automatics-perks\automatics-paired\result.txt`.
- **Startup checks**: `uzdoom.exe -norun` on DOOM.WAD E1M1, stock and with DRLA + doomerfall.pk3: exit 1337 (57 as a
  byte) both.

Failed approaches / test limits:
- The harness cannot hold a real trigger: a console `+attack` (even delayed with `+wait`) never shows in
  `player.cmd.buttons` on the private desktop. The harness pulls the trigger with `FireWeapon` instead, so DRLA's
  spin-up guns (Chaingun, Minigun) fire only a short string per pull; they are checked with fewer shots. The unused
  `autotest_hold` mode is left in the harness for a run on a real desktop.
- The first paired run failed to attach (bridge error -5): the borrowed launcher was built from another branch. The
  play folder now has this branch's launcher.

Known gaps:
- A projectile from an Automatics gun that lands in a later tic gets the damage bonus but not the burst bonus (no
  DRLA rapid-fire gun found that fires projectiles; not checked).
- Damage is attributed to the gun held when the hit lands.
- The sheet grew to 162 ints. Other perk lanes that also append to the sheet will conflict on indices and format
  version at merge; renumber then.
