# devtravel 01: dev mode reveals half the dungeons on the travel map

Card: `work/queue/devtravel/01.opus.dev-travel-anywhere.md`. Owner waived full testing; basic test only.

## How to turn it on

- Staged build: run `play-dev.bat` instead of `play.bat` (install.py now writes both). `play.bat` is unchanged.
- By hand: add `--dfu-arg -dfdevtravel` to the launcher line (it is a Daggerfall Unity command-line flag).
- Off (no flag): nothing changes.

## What it does

`daggerfall-unity-master/Assets/Scripts/Doomerfall/DoomerfallDevTravel.cs`, hooked with one line in
`DoomerfallBridge.Awake`. When a game starts (new character or classic start) and after every load, it walks every
classic location with a dungeon (dungeon type byte 0-18, all four size classes) and marks the ones whose MapId hash
(lowbias32, fixed seed `0xDE7A0001`) falls below 0.5 as discovered in `PlayerGPS`'s discovery data. It only adds
entries, never removes, so the other half can still be unlocked the normal way, and saves made with the flag keep the
added discoveries. The pick is the same half every run. It logs counts by dungeon type and area level, plus examples,
to `run\df.log` (lines starting `devtravel`).

- Daggerfall Unity CliBuild: `CliBuild result: Succeeded`. UZDoom unchanged (built only because install.py always
  builds it, in `D:\dev\DoomDaggerfall-build\devtravel`).
- Stage: `D:\dev\DoomDaggerfall-loop\review\devtravel-stage` (install.py `--keep-data`, data and `dfitems.pk3` seeded
  from `review\batch6-stage`, which was built from the same integration commit).
- One 90 s paired launch through quiet_run.py (launcher `--minimized`, `-dfsynctest` town start plus `-dfdevtravel`).
  `df.log`:
  - `devtravel (new game): 4232 dungeons, 2110 picked, 2017 newly discovered, 93 were already known`
  - picked by type: every one of the 19 types, from DragonsDen 26 to Cemetery 389 (Crypt 134, VampireHaunt 114, ...)
  - picked by level: every level 1-30 has 62-81 dungeons (level 25-30: 72, 81, 71, 64, 78, 78)
  - examples: The Citadel of Kherdar (Alik'r Desert, DesecratedTemple, level 29), Ruins of Rlold'kern Tower
    (Alik'r Desert, DragonsDen, level 26), Ruins of Racher Manor (Alik'r Desert, HumanStronghold, level 26)
  - a second pass right after added 0 (idempotent).
- Not checked: the travel map itself, actual travel, a real New Game through Doom's menu (owner play-test).

## Play-test list (owner)

- Run `play-dev.bat`, make a character, open the travel map: about half the dungeons show, of every type.
- Fast travel to a level 25-30 dungeon and go in.
- Unlock a hidden dungeon the normal way (asking around, a quest) and see it appear.
- Save, quit, run plain `play.bat`, load: the revealed dungeons stay (they are in the save); a new character with
  `play.bat` sees only the normal starting set.
