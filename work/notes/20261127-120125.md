# Shop levels 4: levels for houses and other town buildings (run 20261127-120125)

Goal: inside a town building that is not a shop, `WorldLevel.Current` gives the owner's chosen level (H2: the
building's own quality through card 01's shop bands, never town size). Guild halls (Mages Guild magic item stock)
follow the same rule. Shops keep their card 01 level.

## Plan

1. `DoomerfallShopLevels.ForBuilding(location, summary)`: shops -> `ForShop`; houses (House1-6), houses for sale and
   guild halls -> level from own quality; anything else -> 0 (area level as before). Done.
2. `DoomerfallAreaLevels.ForCurrentPlace`: inside a building, its `ForBuilding` level (cached per building entered);
   otherwise the old rule, now named `ForCurrentDanger`. Done.
3. Keep enemies on the danger level (see Decisions). Done.
4. Python reference in `tools/shop_levels/shop_level.py` (`building_level`) and a runtime dump check. See Results.
5. Paired run: walk into a house in the test town and log `WorldLevel.Current` inside (`-dfbuildingleveltest`).
   See Results.

## Decisions (engineering calls; the owner may overrule)

- **"Through the shop band mapping of card 01", made exact.** Card 01 ranks shops in a band by (quality, town class,
  seed). A house cannot use the town class (owner: no town-size effect), so a building of quality q takes the span
  of levels that the classic shops of quality q hold, all town classes together, and its seed picks its place in
  that span: `place = first + (seed * (end - first) >> 32)`, `level = lo + place * width / shops in band`, where
  `[first, end)` are the band's sorted classic shop keys with quality q. Same seed function as shops (MapId, type,
  NameSeed). So a quality-q house lands on exactly the levels a quality-q shop can have, whatever its town. Quality 0
  (6,146 houses) has no shops and sits at level 1; quality above 20 would sit at 30. Integer math, so Python and C#
  agree exactly. It reuses card 01's table: no extra data, no extra warm-up.
- **Which buildings:** House1-6, HouseForSale (both take quality and NameSeed from their BLOCKS.BSA record, since
  Daggerfall Unity only merges MAPS.BSA list entries into named buildings) and GuildHall (all guilds: Mages, Fighters,
  knightly orders, Thieves/Dark Brotherhood fronts). The card names houses and the Mages Guild; applying it to every
  guild hall is the same rule from the building's own quality. **Taverns, temples, banks, libraries and palaces keep
  today's level** (the area/terrain level): the owner did not choose for them, and the research notes say they roll
  nothing level-dependent except through quests. Question for the owner.
- **Not limited to towns.** Houses on farms and manors also get their own quality level; the rule never reads the
  town, so there is nothing town-specific to check. Shops already exist only in towns and castles.
- **Enemies keep the danger level (new `WorldLevel.Danger`).** `WorldLevel.Current` is read for loot *and* for
  enemy stats (class enemy level and HP, city guard level, enemy starting equipment, melee timer, random encounter
  choice). The owner's H2 is about wealth ("wealthy homes have better loot") and said the town level stays danger
  only. If every read followed the building, a quest foe or guard inside a quality-18 house would jump to level
  25-30 while the same foe outside the door is at the terrain level, which changes combat. So those six reads now use
  `WorldLevel.Danger`, which is `Current` except that a building's own level never applies (provider
  `DoomerfallDrops.CurrentDangerLevel` = the old place rule). Outside a bridge session `Danger` is `Current`, so
  normal Daggerfall Unity is unchanged. Everything else rolled indoors (house containers through `LootTables`, Mages
  Guild magic items, shelves, `ItemBuilder` loot) follows the building. Enemy *loot* (`LootTables`) indoors follows
  the building too, because house containers use the same function; noted below.
- **Doom ammo tier fallback** (`DoomerfallAmmo.AnswerLevels`, when Doom does not know the pixel yet) now calls
  `ForCurrentDanger`, which is exactly what it got before, so ammo tiers do not change.

## Findings

- The research table in section 5 counts houses by their BLOCKS.BSA record quality (mostly 4-7). The MAPS.BSA list
  also holds house entries (209,632 in towns) with a shop-like quality spread, but Daggerfall Unity ignores them for
  houses (`RMBLayout.GetLocationBuildingData` merges only `IsNamedBuilding` types). The level must come from the
  runtime `BuildingSummary`, which it does. My first Python draft read the list and was wrong; it now checks the
  runtime dump's own inputs instead.
