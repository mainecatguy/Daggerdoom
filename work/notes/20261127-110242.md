# Value and weight for every supported mod's weapons: real weaponsmith and pawn shop (run 20261127-110242)

Continues run 20261127-095003 (notes `work/notes/20261127-095003.md`: rules, support file, code). That run built
`WeaponValues.txt` (327 weapons), the value and weight code and the manual entry, and sold Doom guns at a general store
plus two Sell windows *retyped* as a weaponsmith and a pawn shop, because its test town (7154) has neither. This run
adds the missing Done-when evidence: a paired run that walks into a **real** weaponsmith and a **real** pawn shop and
sells a Doom gun in each.

## Plan

1. Find a converted town with both shop types; make the test's town configurable. Done: group **9183** (the city of
   Daggerfall: 1 weaponsmith, 6 pawn shops, 4 armorers, 10 general stores; `DungeonConverter --group 9183
   --list-buildings`). Earlier runs had already converted it (`review/arrival-pause/data/cache/T09183.ddt`); the test
   copies that local file (game-derived, never committed). Interiors convert at runtime.
2. Start position: **not needed**. Daggerfall's `-dfsynctest` start is map pixel 207,213, and the run shows Daggerfall
   already in that pixel when Doom starts at DDT09183 (`sync engaged=True ... pixel=207,213 teleports=0`); position sync
   teleports Daggerfall to Doom's pixel anyway when they differ (`DoomerfallPositionSync.cs:320`).
3. Make the shop route work in the city's shops (see Findings), rebuild Daggerfall, run both, verify.

  cache; `assemble` keeps the review folder's UZDoom, bridge and launcher when the staged build it came from

  the weaponsmith of Daggerfall city.

  retyped windows; it logs the shop type; the shotgun is given (and so sold) first. No game code changed this run.

## Findings and failed approaches

- First weaponsmith run: the 6 shelf presses ran, but neither shopkeeper press reached Daggerfall (no `items: use` /
  talk in the Daggerfall log). The harness stood 56 units from the NPC on the side the player came from, which in this
  shop is behind the counter or in a wall, so Doom's NPC pick (`DD_InfoUseNpc`) found nothing. Fixed in the harness by
  searching around the NPC for a clear spot (`NDSTAND clear spot, 56 from the shopkeeper`).
- First pawn shop run: Use reached a customer ("Edwyctor Ashcroft", faction 0: a plain talk window), who stood nearer
  than the shopkeeper. Daggerfall treats only an NPC whose faction is in the Merchants group as the shopkeeper
  (`PlayerActivate.cs:1613`), and Doom's NPC actors carry no faction, so the harness presses each NPC in turn; the
  Daggerfall hook answers the first merchant menu with Sell.
- A Sell pays less than the listed shop price: Daggerfall's own sale rule with the blank test character's Mercantile
  (Steel Shotgun: price 118, paid 29). Daggerfall items sell the same way; nothing changed there.
