# Starting gun by weapon skill (startgun 01), 20261126-231433

## Plan
1. Doom already reports its starter pistol (class, slot, start ammo N) on a plain load (`DFB_KIND_STARTER`). Send it on
   every New Game arrival too, so Daggerfall knows N and whether DRLA is loaded (`RLPistolPickup` vs `Pistol`).
2. On a bridged New Game arrival, Daggerfall builds the kit from the owner's table and gives it the way a plain load
   gives the starter pistol (`BeginPlainStart`): Doom keeps only its fist (`DFB_GUN_CLEAR`), the guns and Regular ammo
   become real Daggerfall items, Daggerfall's ammo stacks set Doom's counters (`DoomerfallAmmo.PreferDaggerfall`), each
   gun goes on its weapon slot key, and the first is drawn. The old adoption of Doom's gun is no longer used on a
   New Game (it stays as the fallback when Doom sends no starter, and for older saves).
3. Test with a Daggerfall test component that holds the six skills at chosen values, and a driver that runs one New
   Game per case, stock and DRLA.

## What changed
- `UZDoom/src/dd_bridge.cpp`: `NgSendArrived(true)` sends `DD_ItemsSendStarter()` first (it used to be sent only by
  `PlainArrived`, which now relies on this). Bridged New Game only: the New Game chain runs only under `-dfflow`.
- `DoomerfallStartingGun.cs` (new): the owner's table, the tie rule, and giving the kit.
- `DoomerfallHotkeys.BeginStartKit`: resets the table (fist only), puts each gun on the first free plain square of its
  slot key, and has Doom keep only its fist; the existing plain-load draw then raises the first gun.
- `DoomerfallNewGame.OnArrived` calls `DoomerfallStartingGun.Give` before Daggerfall's start. `DoomerfallBridge`
  routes `KIND_STARTER` to it and wires Hotkeys/Ammo.
- Test: `DoomerfallStartingGunTest.cs` (`-dfstartguntest <skills>`, attached by a one-line hook in the bridge) and
  `tools/starting_gun/run_starting_gun.py`.
- `manual.md`: "Your starting gun".

## Decisions (engineering calls within the owner's design)
- **Tie: every tied gun** (the owner's preference; it was easy). Each ammo type is given once, at the largest amount
  any tied gun gets: Rifles+Pistols gives pistol, carbine and N bullets (not 2N). Pistols+Shotguns gives N bullets and
  N/3 shells. The first tied gun in the table's order (Pistols, Rifles, Automatics, Shotguns, Explosives, Melee) is
  drawn; the rest are on their keys (or in the inventory when the key's three plain squares are full).
- **N** is Doom's own starter amount, as the plain load uses it: 60 bullets with DRLA (DRLA's no-class pistol loadout,
  via `DoomerfallPlayer`), 50 stock. N/3 and N/5 round down: 20 shells / 12 rockets with DRLA, 16 / 10 stock.
- **DRLA detection**: by Doom's starter pistol class (`RL...` = DRLA's `RLPistol` is loaded), which is how Doom
  already chooses the pistol.
- **Slots**: Doom's weapon slots, the same in stock and DRLA: chainsaw 1 (after the fist), pistol 2 (Doom's report),
  shotgun 3, chaingun 4, Light Carbine 4, rocket launcher 5.
- **"None highest"**: all six skills exist now (skillcore), so this only happens when all six are 0; then the starter
  pistol and N bullets.
- **Medieval-only option later**: `DoomerfallStartingGun.Kit` returning no guns leaves Doom with only its fist and no
  ammo; nothing else would need to change.
- **Material**: each gun gets a fixed seeded material roll per class (the same seed the adoption used), so every new
  character with the same gun gets the same material.

## Known gaps
- The adoption still runs briefly during the hold and its pistol is then removed. Harmless (logged), but a little
  wasteful; skipping adoption while a New Game is held would need a change in DoomerfallHotkeys.Update's timing.
- Starting gun material uses the same fixed per-class seeded roll the adoption used, so some starting guns are Steel
  or Silver (e.g. the DRLA shotgun is Silver, the stock pistol Silver). Iron for every starting gun might fit "weakest,
  most basic" better; left as it was, since it is the existing rule.
- A plain Daggerfall save load with no Doom gun still gets the pistol (the owner's 2026-11-24 rule), not the
  skill-based gun. Asked below.
- Not tested: a non-flow bridged New Game (Daggerfall's own New Game with no `-dfflow`); it keeps the old adoption.

## Play-test list
- New Game with a class whose best gun skill is Shotguns (e.g. Warrior, Spellsword): the shotgun is in your hands,
  20 shells, no pistol in the inventory; key 3 raises it.
- A class with Rifles highest (Archer, Ranger): Light Carbine on key 4, 60 bullets.
- Melee highest (Barbarian, Knight): the chainsaw comes up; it is on key 1's second square; no ammo.
- Make a custom class with two gun skills tied: both guns, one is in your hands.
