# Approved material odds for all loot (run 20261124-114307)

Branch `agent/oddseverywhere-20261124-114307`, from `integration` after the `arealevelall` merge (344818a).

## What changed

- `FormulaHelper.RandomMaterial` already had a Doomerfall hook (`DoomerfallMaterialRoll`), but
  `DoomerfallDrops.RollEnemy` set it only while a slain Doom enemy's drop was rolled. `DoomerfallBridge` now sets it
  to `DoomerfallDrops.RollMaterial` when the session attaches, next to the `WorldLevel` providers, and clears it in
  `OnDestroy`. One hook covers everything: `RandomArmorMaterial` reaches it through its plate branch, and treasure
  piles, enemy loot, shop shelves (including modded weapons and armor), house containers, the Mages Guild magic item
  stock, and enemy starting equipment all roll materials through these two functions, at `WorldLevel.Current`.
- `RollEnemy` saves and restores the hook instead of clearing it, so a Doom drop roll does not switch the session off.
- Outside a bridge session the hook is null, so normal Daggerfall Unity runs the classic formula (or a mod's
  override) exactly as before.
- Ammo tiers (`DoomerfallAmmoTiers`) never used this hook and are unchanged.
- Fixed loot seeds still hold: `RollMaterial` draws from Unity's generator, which `LootSeed` seeds.

## Constrained calls I made (see questions)

- Armor still picks leather 70% / chain 20% / plate 10% first (Daggerfall's `RandomArmorMaterial`), and only plate
  gets an approved tier. Slain Doom enemies' drops already worked this way, so I kept it consistent. Measured:
  leather 69%, chain 20%, plate 11%.
- Quest reward magic items (`Questing/Item.cs:340`) pass the player's level (owner: quest reward scaling unchanged
  for now). With the hook on for the whole session they get the approved odds at the player's level.

## Test

`-dfworldleveltest` now also runs `DoomerfallMaterialOddsTest.cs`. At area levels 1, 10, 20 and 30
(`WorldLevel.Scope`) it does 400 seeded rounds of: treasure piles for keys A to U, shop shelves (weapon smith,
armorer, pawn shop, general store; quality 20), house containers for every house type with container models
0/2/4/11/15, 10 Mages Guild style `CreateRandomMagicItem` calls, and class enemies' equipment (Knight, Warrior,
Barbarian, Spellsword; every fourth round). It counts the tiers of weapons (arrows excluded, they have no material)
and plate armor. Then it repeats level 20 with the hook off (classic) as a control. The world level test's control
section also switches the hook off now, so it is exactly normal Daggerfall Unity.

`world_level.py odds N` computes the approved table separately in Python from the formula in
`20261123-material-tier-proposal.md` (it reproduces that table) and passes when every tier's |z| < 4.
