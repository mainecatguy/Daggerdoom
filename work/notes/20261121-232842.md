# Run 20261121-232842: dungeon converter

Full findings, measurements, failures, and the play-test list are in `dungeon-converter-results.md`.

## Plan as executed

1. Link Daggerfall Unity's real readers into a command-line tool.
2. Rasterize real dungeon geometry into vertical spans and emit UDMF with solid 3D floors.
3. Build an in-engine check for points, moves, doors, falling, sight, projectiles, and chasing.
4. Develop on Privateer's Hold, then run the same converter on Scourg Barrow.

## Decisions

- Used stock UDMF 3D floors because real data never produced a failure that justified an engine patch.
- Kept moving models static. Implementing Daggerfall's action system is outside this goal.
- Did not tune the converter to Scourg Barrow's crypt. The cause is unproven and may be a rare case.

## Next steps
