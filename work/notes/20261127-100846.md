## Findings

- **Load screenshot (harness bug).** `harness.zs` stopped every phase `>= 9`, and the load path's phase is 20, so after
  listing the corpse it never got to its screenshot. Now only phase 9 is the end.
- **Guard corpses were never kept (real bug).** The first live guard run: Doom laid the blood and sent the place, but
  Daggerfall logged `corpse: 8000000000000001 is no Daggerfall person this keeps`, then `guards: death
  8000000000000001, removed Daggerfall's copy`. So the copy existed, but `DoomerfallGuards.CorpseOf` found no
  `MobileUnit`: it used `GetComponentInChildren<MobileUnit>()`, which skips inactive objects, and Daggerfall's inert
  guard copy can be inactive (the guard test already notes this). Fixed with `GetComponentInChildren<MobileUnit>(true)`.
  The blood splash itself worked (`run\guard\gblood.png`).
