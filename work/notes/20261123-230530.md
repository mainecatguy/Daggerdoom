## Findings
- `review\stationary-npcs\data` works with this branch's UZDoom. Doom enters the dungeon, and Daggerfall lists its piles.
- Loading a save restores a non-static ZScript event handler's fields from the save. `WorldLoaded(IsSaveGame)` changes made before that are lost, so a harness that keeps its state in fields cannot use `WorldLoaded` to notice a load.
- `const X = 0;` with `if (X) break;` inside a `switch` case hung UZDoom at map start. The load run (`X = 1`) did not hang. I did not track down the cause in UZDoom's compiler, and the harness now avoids that pattern.
- The game-side test switch `-dfdoomitemstest` remains. It is off unless passed, like `-dfsynctest`, `-dfloadtest`, and `-dfsavetestfail`.
