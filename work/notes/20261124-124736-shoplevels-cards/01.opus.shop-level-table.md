# Shop levels 1: the shop level table

Read D:\dev\DoomDaggerfall\AGENTS.md first. The design is `work/notes/20261124-124736-shop-levels.md`. The research
scripts are in `tools/shop_levels/`.

**Needs the owner's choice of formula** (proposal C is recommended; A and D are also contract-safe). Build the
chosen one.

## Goal
Every classic shop has a fixed level from 1 to 30, computed from the classic data alone, available to Daggerfall's
side by building. Nothing uses it yet.

## What to build
- In `DoomerfallAreaLevels` (or a sibling `DoomerfallShopLevels` that warms on the same worker), read every
  location's building list from MAPS.BSA. Shop type and quality come from `Exterior.Buildings`, and the town class from
  the location type plus the capital rule (the city named after its region, with the aliases in
  `tools/shop_levels/proposals.py`).
- Proposal C: band ranges 1-3 → 1-4, 4-7 → 5-10, 8-13 → 11-18, 14-17 → 19-24, 18-20 → 25-30. Inside a band, order by
  (quality, town class, fixed seed), using the cell-count form in the notes (counts per band, quality and town class
  cell, then the seed within the cell). Choose a building seed that is stable classic data and is available at
  runtime from `BuildingSummary`, such as MapId plus the building key. Document it.
- `ForShop(DFLocation, BuildingSummary) → level` (0 if not a shop), and a mod-added location falls back to the formula
  with its own counts left out (classic levels never move).
- A Python port in `tools/shop_levels/` that gives the same level for every shop, the same way `area_level.py`
  mirrors `DoomerfallAreaLevels`.

## What must stay true
- Pure function of classic data: same level in every game, save and launch. Never reads the player.
- The band contract: no shop sits below the top level of the band beneath its own.
- Warm-up stays off the main thread. Report the extra milliseconds.

## How to prove it
- A `-df...` test hook (own file, one line in the bridge) logs the level of a list of shops, including Gothway
  Garden's and the City of Daggerfall's, and the per-level counts. The counts match `tools/shop_levels/proposals.py`,
  and the per-shop levels match the Python port exactly.
- The contract check passes over all 14,790 shops.
