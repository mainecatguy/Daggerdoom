# New start 1: remove the Reflexes choice (20261124-104520)

## Plan
1. Find the Reflexes step in Daggerfall Unity's character creation.
2. In a Doom flow session (`-dfflow`), skip it and give the new character the Normal value.
3. Leave plain Daggerfall Unity launches and old saves alone.
4. Prove it: New Game through the launcher (`--minimized`), and a plain Daggerfall Unity launch.

## Findings
- Reflexes appear twice in creation:
  - Wizard step `CreateCharReflexSelect`, reached from the bonus skills screen's OK
    (`DaggerfallStartNewGameWizard.cs` AddBonusSkillsWindow_OnClose) and from the summary screen's back
    (SummaryWindow_OnClose, cancelled branch).
  - A `ReflexPicker` on the summary sheet (`CreateCharSummary.cs`), which writes back into the character document.
- `PlayerReflexes` (`EntityEnums.cs:171`): VeryHigh=0, High=1, Average=2, Low=3, VeryLow=4. **Normal = `Average`**,
  the middle choice, as the card says. It is also Daggerfall's own default (`CharacterDocument.cs:78`,
  `ReflexPicker.cs:98`), so Average is what a player who just pressed OK on the old screen got.
- Old saves: reflexes come from `SerializablePlayer.cs:279` (`entity.Reflexes = data.playerEntity.reflexes`).
  That path is not touched, so loaded characters keep what they had.

## What changed
- `DoomerfallNewGame.FixedReflexes` (true only when `-dfflow` started a flow session on a portable install, the same
  condition as `HoldsNewCharacter`) and `DoomerfallNewGame.NormalReflexes = PlayerReflexes.Average`.
- Wizard: in a flow session, the bonus skills OK sets `reflexes = Average` and goes straight to the summary. Back from
  the summary goes to the bonus skills screen instead of the Reflexes screen.
- Summary sheet: in a flow session the reflex picker ignores clicks, so it stays on Average (it still shows the
  highlight, see play-test list). Outside a flow session it works as before.
- The New Game log line (`new game: ... held at ...`) now also prints the character's reflexes.
- Test only: `DoomerfallReflexProbe.cs` (`-dfreflexprobe <Daggerfall folder> <report>`), a plain launch with no
  bridge. Opens the real wizard, goes to the bonus skills screen, presses its OK (CloseWindow), and reports which
  screen came next.
