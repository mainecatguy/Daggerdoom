# Luck: a 0-50% chance for each kill to drop ammo (run 20261127-112323)

Goal: every kill has a Luck/2 percent chance to drop ammo (0% at Luck 0, 50% at 100), base 0%. Remove the old
Luck-in-100 extra-ammo rule (attributes 04, run 20261127-034545). Doom rolls; Daggerfall sends Luck as now.

## Plan

1. Replace `DoomerfallAmmoTiers.LuckDrop` (extra copy of an existing monster ammo drop) with a per-kill roll in the
   same handler's `WorldThingDied`. No engine change, no bridge change, no Daggerfall change.
2. Rewrite `tools/luck/luck_paired.py` to measure the per-kill drop rate against Luck/2 at several Luck values, stock
   and DRLA, on the real paired game (fixed-drops harness: New Game, Privateer's Hold, kill the monsters near the start).
3. Manual's Luck line.

## What was built

- `mods/doomerfall/src/zscript/DoomerfallAmmo.zs`:
  - `WorldThingDied`: in a Daggerfall session (`rules`, area level known), for a dying monster with a fixed loot seed
    (`DD_LootSeed() != 0`: a monster Daggerfall placed), read live Luck (`DD_SheetStat(7)`, as before). Luck <= 0 (or
    -1 with no character / plain Doom): nothing. Else hash the seed with the Luck salt; drop when
    `roll * 200 < min(Luck, 100)`, i.e. Luck/2 percent.
  - The drop is one ordinary monster ammo drop: half a small pickup (Doom's dropped-clip size), tier from the area
    level's usual odds, including the 2% jackpot, via the new `Drop()` that `Convert` now also uses (pure extraction,
    same numbers and same seeds for converted pickups).
  - The old `LuckDrop` and its call in `Convert` are removed.
- Diagnostics (log file only; on screen only with `dd_debugmessages`): `DFAMMO luck kill <class> luck L roll R
  drop|none` for every roll, `DFAMMO luck drop <type> ...` before the drop's own `DFAMMO drop|jackpot` line.
- `manual.md` Luck line rewritten.

## Engineering / constrained calls (owner may want to change)

- **Which ammo:** the goal does not say. I picked one of the four types evenly at random (from the same hash), not
  "ammo for the gun you hold" — the latter would be a bigger design change (Luck would also choose useful ammo).
  Asked as a question.
- **Size:** a small dropped pickup (10/2 = 5 bullets, 2 shells, 1 rocket, 10 cells), like Doom's dropped clip.
- **Jackpot:** kept, since it is an ordinary ammo drop; 2% of Luck drops become a 20-pickup (10 rockets) town-tier pile.
- **Which kills:** monsters Daggerfall placed (fixed loot seed). Summoned and revived monsters roll nothing, matching
  the existing rule that they drop nothing (no farming a Pain Elemental). Kills by other monsters count too (the goal
  says every kill).
- **Determinism:** the roll is a hash of the monster's fixed loot seed, like the rest of the loot, so a kill rolls the
  same number every game and a luckier character gets every drop a less lucky one gets. Spawned during the death's loot
  scope, the pickups get their own per-class loot ids, which do not touch the counts of any class the monster's own
  loot spawns (dd_lootrng.cpp `DD_LootInherit`).
