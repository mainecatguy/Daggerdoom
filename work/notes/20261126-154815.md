# Rifles skill — 2026-11-26 (run 154815)

Goal (`skillcore` 04): add Rifles the way card 01 added Shotguns, Automatics and Explosives and card 03 added
Pistols. Skill only, no perks. Done when Rifles shows on a new character's sheet, Doom receives its value, a save and
load keeps it, and an old save loads. Do not change class lists.

## Plan
1. Rifles takes slot 8 (classic Nymph), the next removed language slot, by the same steps as Pistols (slot 7).
2. Keep class lists unchanged: data written before Rifles still reads slot 8 as Nymph and gets card 01's filler.
3. Bridge: `DFB_SKILL_RIFLES 8`, sheet format 4 → 5, log lines carry rifles.
4. Doom: `DoomerfallWeaponCategory.SkillSlot(Precision)` → 8.
5. Build UZDoom, bridge, launcher, Daggerfall Unity; run the weapon category test, the paired sheet test
   (old save, raise, save/load, new character), stock E1M1.
6. Demo, manual, notes.

## Dependencies on other cards
`rifletag` 01 (Doomerfall's own rifle tag on every DRLA rifle) and `lightcarbine` 01 are todo items that are **not
built** on this branch or any branch I could find (`git log --all` has only the Rifles design commits). This card
does not need them for its "done" line (sheet, Doom value, save/load, old save). Until the rifle tag exists, Doom's
rifle category is DRLA's single-shot rifle token (the existing `Precision` category), which is a correct subset of the
owner's rifle definition: every non-cell, non-rocket gun carrying that token is a ballistic rifle. Rifles without
the token (Sniper Rifle reads Other; Battle and Vanguard Rifles carry the rapid-fire token and read Automatic) are
left for `rifletag` 01, which owns rifle membership.

## What was built
### Daggerfall
- `DFCareer.Skills`: `Rifles = 8`; `Nymph = 8` stays as an `[Obsolete]` alias like the other old language names.
  `IsRemovedSkill` is now slots 9-12 (Daedric..Impish).
- `RemapRemovedSkills(Skills firstLanguageSlot = Daedric)` replaces card 03's `bool slot7IsDragonish`: every listed
  slot from `firstLanguageSlot` to Impish counts as a language and gets card 01's filler (same formula, same pool of
  Shotguns/Automatics/Explosives). Callers:
  - classic `CLASS*.CFG` data → `Pistols` (slots 7 and 8 are Dragonish and Nymph), so classic classes are unchanged;
  - saves → `DaggerfallSkills.FirstLanguageSlotOf(skills)`: skills format < 2 → Pistols, format 2 (Pistols-era) →
    Rifles, format 3 → Daedric. A custom class saved with Rifles keeps it.
  So **no class list changes**: a class listing Nymph still gets the filler it got before (Automatics if free).
- `DaggerfallSkills`: field `Nymph` renamed `Rifles`; a save without the field (every save before this change) starts
  Rifles at Daggerfall's untrained default (random 3-6), the mechanism cards 01 and 03 used. `GunSkillsFormat` now
  written as 3 (`HasRiflesSlot`). Governing stat **Agility**, advancement multiplier **2** (placeholders, like the
  other gun skills; Agility matches Pistols and Daggerfall's Archery). Classic import resets slots 4-8 to untrained.
- Name "Rifles" (`riflesSkill` key, English fallback). Fighters Guild training list gets Rifles.
- Unchanged on purpose: slot 8 stays a legacy language slot for biographies and Enhances Skill (`IsLegacyLanguageSlot`
  4-12), so an old "Enhances Nymph" item still says "Nymph (no effect)" and gun skills still cannot be enchanted.
### Bridge

  `rifles b/l`.
### Doom
