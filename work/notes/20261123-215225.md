# Quiet agent launches

Goal: programs that agents and the overnight harness start open minimized, make no sound, and do not flash or take focus.

## How it was measured

`tools/quiet_probe/quiet_probe.py` runs any command and watches its whole process tree for:

- **shown**: a top-level window shown on screen and not minimized, even for a moment (WinEvent `EVENT_OBJECT_SHOW`)
- **onscreen**: a window seen on screen by a 50 ms poll
- **focus**: a window of the tree became the foreground window
- **flash**: a taskbar flash request (`HSHELL_FLASH` from a shell hook)
- **audio**: a Windows audio session of the tree, and its peak meter (above 0 means real sound)

`tools/quiet_probe/self_test.py` checks the probe with signals too small to notice: a 3x3 pixel window shown without
activation, one taskbar flash, and a -60 dB tone, then a silent command. Result: `PASS` (shown 1, flash 1, onscreen 1,
audible session 1, then nothing).

Limit: sounds that Windows plays for a process in the shared "system sounds" session, such as the message box error
chime, are not tied to the process and are not counted.
