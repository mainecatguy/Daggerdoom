# 20261123-225515: area level proposal

Goal: a quick proposal for how every Daggerfall location gets an area level from 1 to 30.
The result is in `20261123-225515-area-level-proposal.md`.

## Plan

1. Read the location data straight from `MAPS.BSA` (names and map table) and `POLITIC.PAK`
   (region per map pixel) with a small Python port of Daggerfall Unity's readers. Done.
2. Score = region lean + smooth geo field + type lean + per-place noise, then rank to 1 to 30. Done.
3. Measure uniformity, region and type effects, clustering, and determinism, then tune. Done.
4. Write up the proposal. Done.

## Findings

- 15,251 classic locations. 4,232 have a dungeon: 1,500 labyrinths, 843 keeps, 1,112 ruins,
  774 graveyards, and 3 cities (Daggerfall, Sentinel, Wayrest) with dungeons. The MapIds in
  `DaggerfallDungeon.IsMainStoryDungeon` match the map table's MapId.
- `POLITIC.PAK` agrees with the map table's region for all but 3 locations. Some politic
  values map past the 62 named regions, and those are treated as not land.
- First pass (region weight 1.0, type 0.45, no exceptions): the starting regions had no
  dungeons at 26-30 at all, and type leans were hidden by geography. For example, dragon's
  dens had a lower median than cemeteries, because most dens are in the Daggerfall region.
  Fixes: rare large "exception" kicks (7%, matching "exceptions break the pattern" in
  `gamedesign.md`), type weight 0.8, region weight 0.85, and a region-adjusted type metric
  in the report.
- Ranking graveyards in their own class makes the cemetery lean meaningless, so it is 0.
- PIL is not installed, so the optional `--png` map is skipped. It is not needed.

## Verification

- `python tools/area_level/area_level.py --csv <scratch>/a.csv`, run twice: identical md5.
- Uniformity: 140 to 145 dungeons per level.
