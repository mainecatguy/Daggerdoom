# Tilted door export crash (20261122-233948)

## Cause
`--export-mesh` on "Daggerfall" threw on door 55004 (block S0000160.RDB): rotation (180, 90, 0), an upside-down door. The door objects only supported yaw.

## Survey
`DungeonConverter --list-tilted-doors` scans every RDB block in BLOCKS.BSA. 2475 door objects, 8 tilted, all rolls of 180 degrees:

| Block | Door model | Rotation (x,y,z) |
|---|---|---|
| S0000004 | 74232 | -180, 0, -180 (net yaw of 180) |
| S0000080 | 55013 (3x) | 0, -90, 180 |
| S0000081 | 55014 (2x) | 0, 90, 180 |
| S0000101 | 55012 | 0, -90, -360 (identity roll) |
| S0000160 | 55004 | -180, 90, 0 (the Daggerfall crash) |

Privateer's Hold and Scourg Barrow have none. Other dungeons that use S0000004/80/81/101 would have thrown too. I only exported and loaded Daggerfall.

## Handling
- Any rotation that keeps the vertical axis vertical is `Ry(phi) * F`, where F is nothing or a 180 degree roll. F is baked into a separate OBJ (`m<id>f.obj`, bounds and normals flipped). `phi` is the closed angle.
- Daggerfall Unity swings a door about its own local Y, which points down on a flipped door, so the swing reverses. DFDOORS gets an optional 12th field, the swing direction (-1 on flipped doors), read by `door_objects.zs`. The old 11-field lines still work.
- A rotation that tips the vertical axis still throws, with a clear message. None exist in the data.

## Verified
- `Daggerfall`, `Privateer's Hold` and `Scourg Barrow` all export with `--export-mesh`. Door counts are Daggerfall 173 (11 models), Privateer's 58 (was 58), Scourg Barrow 212.
- Privateer's Hold DFDOORS placements are identical to the earlier export apart from the new trailing `1` and `-0.000` vs `0.000`.
- Full Daggerfall conversion, then UZDoom load (private config, 30 s): `DFDOORS spawned 173, sight links 173`, `DFACTIONS loaded 156 records`, no errors in the log.

## Not verified (play-test list)
- Door 55004 (block S0000160) appearance: right side up in the frame, not clipped into the floor or ceiling when closed and open.
- That it swings the same way as in Daggerfall Unity, and collision matches.
- Doors 55013, 55014 (mirrored with rz 180) have only been exported, not looked at.
- The Privateer's Hold and Scourg Barrow door runtime were not re-run in-game (the placement data is unchanged).
- `door_check` was not run on Daggerfall.
