# perknumbers 01: the owner's perk numbers (2026-11-28)

Goal: send the owner's numbers (Q&A items 11-14, `gamedesign/decisions/20261127-qa-batch2-owner.md`) for Explosives
50's direct-hit bonus, Inpulsa's Broken Heart and the Shotguns slam, and show each live in a test.

## What I found

The card was written before the "one pattern" rules change (`e69179b0`): Daggerfall no longer sends perk rule values.
It sends the character sheet, and Doom computes every rule in `DoomerfallRules.Compute`. In that function:

- `ExplChainBp` was already 2500 at 100 and `ExplChainRadius` 128, and the blast already goes through
  `RadiusAttack(..., 128, ...)` with no full-damage radius, which is rocket falloff. Chain blasts are untagged, so the
  Explosives, Strength, Agility and Luck modifiers all skip them.
- `ShotSlamDamage` was already 200 at 75 and 400 at 100.
- Only `ExplDirectBp` was still 0. That was the one real gap.

## What changed

- `DoomerfallRules.zs`: `ExplDirectBp` is 5000 (+50%) from Explosives 50. It multiplies with the skill's damage bonus
  on the direct hit only, so the direct hit at 50 is x1.3 x 1.5 = x1.95 and the splash stays x1.3.
- Updated comments in `DoomerfallRules.zs` and `DoomerfallExplosives.zs`, plus the bridge header comment for slot 164
  (regenerated `DoomerfallBridge.g.cs` and `doomerfall_bridge_check.g.h` with `bridge/generate_bindings.py`). This is a
  comment-only change: the layout is the same.
- Perk window text (`DoomerfallPerks.cs`) for Explosives 50 now gives the number and is marked built. `manual.md`
  Explosives 50 now says what it does instead of "does not work yet".
- New test: `tools/perknumbers/perknumbers_test.py` + `.zs`. The fake Daggerfall peer writes a **real character
  sheet** (live and base skills, attributes), with no hand-picked rule set and no `dd_ruletest`, so the numbers come
  from `DoomerfallRules.Compute`. The older per-skill tests feed rule values directly.

## Things I tried that failed

- The first run used the `verify-batch13` build. That build uses sheet format 13 / 203 ints, so it treats this branch's
  sheet as invalid and every rule reads off. I switched to builds made from this worktree.
- The first chain layout put dummies on both sides of the rocket's path facing east. The south side and the spot
  behind the monster were out of sight or in walls in E1M1. Now everything goes north, behind the monster, into the
  open room.
- Running `play.bat` through `quiet_run.py`: the bat's `start` detaches, so the timeout did not stop UZDoom. I stopped
  the two leftover processes by PID.

The skillperks 03 card says chain blasts halve each generation, and the code still does that. Item 13 says "always
explodes for exactly 25% of the monster's HP without other bonuses". I read that as being about bonuses (the question
asked), so I kept the halving: the first blast is exactly 25%, the second 12.5%, and so on.
