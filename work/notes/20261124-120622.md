## Findings
- The converter already writes a checked walk graph per dungeon; A* on it takes milliseconds. Sector A* is not
  worth building.
- Daggerfall windows reach Doom as pixels, so window text needs a Daggerfall-side reader (design section 4).
- Doomerfall has no levitation yet (no code maps Daggerfall's Levitate to Doom flight), so routes that need it cannot
  be walked honestly.
- Live monsters block corridors even in god mode; honest completion needs honest fighting.
- With the loose smoothing, `goto` walked into a wall corner; fixed with a link-following check.
