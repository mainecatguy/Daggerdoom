## Fog and foggy sky: how

| Piece | How |
|---|---|
| Bridge | `DoomerfallWorldLook.cs` also sends `fog <on> <mode> <density> <start> <end> <r> <g> <b> <sky>`: Unity's `RenderSettings.fog`, `fogMode`, `fogDensity`, `fogStartDistance`, `fogEndDistance`, `fogColor`, and `!currentOutdoorFogSettings.excludeSkybox`. These are what `WeatherManager.SetFog` and `DaggerfallSky.SetSkyFogColor` left, so clear (linear 0 to 2400 m, sky colour), rain, snow, heavy fog (grey), interior (0.001/m black) and dungeon (0.005/m black) all come from Daggerfall at run time. Nothing is hard-coded on the Doom side. Without the line (older Daggerfall builds) Doom keeps its weather table. |
| Linear fog | Doom has only exponential fog (`exp(-d x dist / 64000)`). Unity's linear fog is matched at half its range (both half fogged at 1200 m for clear weather): per metre `ln 2 / ((end - start) / 2)`. Nearer than that Doom's fog is a little thicker, farther a little thinner. |
| Fine density | Sector fog density is a whole number and clear-weather fog is about 0.49. While Daggerfall's fog is on a map, its sectors hold densities in 1/16 steps; `hw_lighting.cpp` multiplies by `dd_fog_unit` (one line), which is 1 on every map Doomerfall has not written. |
| Black fog | Doom treats black sector fade as its light-level distance shading, not fog, so Daggerfall's black interior and dungeon fog is sent as colour (1,1,1), which Doom draws as real fog. |
| Places | Exterior: all sectors and the town mesh. Interiors and dungeons: sectors and mesh get fog only when the `fog` line arrives; their light is unchanged as before. |
| Sky | `UpdateSky` fills `DFSKY` with the fog colour when the line says the sky is fogged. Unity's 0.05/m fog at sky distance leaves only fog colour, so a solid fill is what Daggerfall shows. |
