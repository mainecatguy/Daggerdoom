# Stand-in for an unaffordable regional favourite (2026-11-27)

Goal: dungeons in one region cell share a favourite kind, guaranteed about 10% of the army (`work/notes/20261124-100533.md`).
A low-level dungeon often cannot afford it. Owner (2026-11-26): pick an affordable stand-in that fits the theme and region,
preferring the favourite's own colour or DRLA family, then the nearest kind on the kind ring. Same seeds, same stand-in.

## Plan

1. Define "affordable" from data the planner already has before the budget runs.
2. In `GuaranteeRegion`, buy an affordable class of the favourite kind. If the kind has none, choose a stand-in.
3. Keep the DRLA family spread from adding unaffordable variants under the favourite or stand-in.
4. Extend the planner test hook and checks, and add a level ladder in one cell.
5. Run the planner and budget tests in every mod setup.

## What changed

- `mods/doomerfall/src/zscript/EncounterPlanner.zs`
  - `plan.regionAfford` (centipoints) = the area level's average points per encounter (budget table, section 6.1)
    × `region_afford` (data file, default 1). A class is affordable when `Cost(m) <= regionAfford`.
  - `GuaranteeRegion`: if the kind is already in the army through any role, nothing changes (as before). Otherwise it
    first picks among the kind's affordable classes, with the same tier-lean weights as before. If none exist, it picks
    among all the kind's classes. That pick only names what the favourite would have been (`army.regionRef`). Then
    `RegionStandIn` chooses the stand-in, added with role `standin`, and `regionHow` becomes `standin`.
  - `RegionStandIn` uses a fixed ranking with no random draw. Candidates are usable, uncapped, not in the army, within
    the colour lock and family rules, of another kind, and affordable. They are ranked by:
    1. Same group as the favourite (the Colourful Hell colour or DRLA family).
    2. Nearest kind along `kind_ring`.
    3. Fits the dungeon's theme (`theme.Matches`).
    4. Most shared look traits with the favourite.
    5. Dearest, which is closest to the favourite's strength.
    If nothing is affordable, the cheapest candidate stands in. That cannot happen with the current data: a Zombieman
    costs 1.0 and level 0 affords 2.5.
  - `Spread`: DRLA family variants of a `region` or `standin` entry must also be affordable. Without this, the spread
    added unaffordable favourite variants. The new check caught 2 to 4 cases per DRLA setup.
- `doomerfall_encounters.txt`: `set region_afford 1`.
- Test hook `EncounterPlannerTest.zs`: it prints `regionafford=` on plan lines and `regionref=` on army lines. It adds
  an 11-dungeon level ladder (levels 0, 3, ... 30) in cell 10,5. The ladder uses only types that every setup has theme
  monsters for, and no Dragon's Den or Vampire Haunt, because those are counted at 120 each.
- `tools/encounter_planner/run_test.py`: new checks for each setup:
  - A favourite class (and its variants) is bought only when affordable.
  - An unaffordable favourite kind that is not already in the army always gets a stand-in. The stand-in is of another
    kind and is affordable, and its reference class really is unaffordable.
  - There are no regional warnings.
  - In the ladder, level 0 uses a stand-in, level 30 uses the favourite, and the ladder dungeons raise no warnings.

## Engineering calls (owner may want to adjust)

- **"Affordable" means one average encounter at the area level can buy it** (`region_afford 1`). An ordinary
  placement gets about the average. A dearer monster would appear only in boss or giant packs, or the reserve would
  absorb it. Rough break-even levels in stock: Revenant about level 5, Archvile about 10, Cyberdemon about 21,
  Spider Mastermind about 22. The setting is a data value.
- **Ring distance does not wrap for the stand-in.** The ring's two ends are Cyberdemon and ZombieMan, which are not
  alike. With wrapping, a stock Cyberdemon's stand-in was a Zombieman. Without it, the stand-in climbs with level:
  Lost Soul, Pain Elemental, Fatso, Arachnotron. The anchor ring still wraps as before.
- **Theme is third in the ranking,** after colour or family and ring distance, following the order the owner gave.
  The theme is already guaranteed separately (`GuaranteeTheme`).
- **The DRLA "Standard" family counts as a family for the group match**, because `families` lists it. A Standard
  RLCyberdemon favourite can therefore get a Standard-family stand-in such as RLMancubus or RLArachnotron.
- **The favourite kind present through another role still counts as present,** even when that class is
  unaffordable, for example a wildcard or support Cyberdemon at level 3 to 9 in the ladder. This is unchanged. Roles
  other than the region guarantee are not limited by price, and the budget decides what really spawns.
