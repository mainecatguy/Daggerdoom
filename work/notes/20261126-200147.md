## 1. PDA Classes page (already done in `b9ba1acb`, checked)

`player.pdap:19-34` builds `PDA_CLASS_<GetActorClass(0)>_NAME/_ABILITIES/_STORY/_HEIGHT`. It trims 3 characters only
when DoomRPG is loaded (`DRPGDRLAActive`), which Doomerfall never loads, so the key is
`PDA_CLASS_DoomerfallPlayer_NAME`. LANGUAGE lookups ignore case, so `drla-src/LANGUAGE.txt`'s
`PDA_CLASS_DOOMERFALLPLAYER_*` match. The portrait is `DRLA_ClassIcon[PlayerClass(...)]`; our class is index 0, which
shows `PPDAMAR1/2`; `drla-src/graphics/PPDAMAR1.png`/`PPDAMAR2.png` are 1x1 transparent, so no Marine portrait.
Contained: only `doomerfall-drla.pk3` has them, it loads only in bridged games, and the Marine can't be chosen there.
Bridged probe: `pda name "No Doom class" portrait 1x1`. **Known limit:** the PDA page was not opened on screen (play-test).
