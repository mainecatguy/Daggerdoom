# The Grammaton Cleric Beretta is a Pistol and an Automatic (20261127-091546)

Goal: DRLA's Grammaton Cleric Beretta counts as both Pistol and Automatic. Owner, 2026-11-27: "Grammaton Cleric
Beretta - Dual tag is pistol and automatic."

## Plan

1. Find where the second category comes from: `DoomerfallWeaponCategory.BothWithTokens`. The Beretta has DRLA's
   pistol, shotgun and rapid-fire tokens, so it hit the Pistol rule with second = Other (it is not energy).
2. Give it Automatic as its second category, on that one rule, for that one class.
3. Add it to both tests and the manual; run both tests, stock and DRLA.
4. Demo.

## Change

`mods/doomerfall/src/zscript/DoomerfallWeaponCategory.zs`, the Pistol rule:
`return Pistol, isEnergy ? Energy : IsClass(w, "RLGrammatonClericBeretta") ? Automatic : Other;`
The Beretta class is looked up at run time, so without DRLA this does nothing. DRLA has one Beretta weapon class
(`RLGrammatonClericBeretta`; the other `RLGrammatonClericBeretta*` actors are pickups, tokens and its clip), so no
variants needed listing.

All three consumers read `BothWithTokens`, so this one line covers them:
- the Type line (`DoomerfallWeaponTypes.Types` -> `BothOfClass`) and the Daggerfall inventory text, which shows what
  Doom sends (`DoomerfallDoomItems.TypesLine`: "Grammaton Cleric Beretta. Types: Pistol, Automatic");
- the weapon-skill lookup (`SkillSlotOf` -> `Both`), which already handles any pair: it picks the higher of the two
  skills from Daggerfall's sheet, the first (Pistols) on a tie or without Daggerfall. Only tests call `SkillSlotOf`
  so far (`DoomerfallWeaponCategoryTest.zs`, `tools/weapon_category/twoskill_paired.zs`). Firing a Doom gun trains no
  gun skill yet, and no Automatics or Pistols perk is built (`DoomerfallPerks.cs`), so the Beretta's second skill has
  no gameplay effect until those exist.

No engine change and no C# change. No other gun changes (the category test's other samples and the 167-gun
description-vs-skill check pass unchanged).

`manual.md`: new bullet under "Weapons that belong to two skills": Pistols and Automatics, the Beretta.
