# Shop levels 3, run 2: town map key from Doom (run 20261127-130007)

Continues `work/notes/20261127-110527.md` (read it for the town class rule, the rectangle, the travel hint and the
first run's results). That run was blocked on three verifier points. The game designer settled the grouped-map

shared Doom map (Daggerfall 20, Ripwych Commons 5). This run does the rest.

## Plan

1. Doom tells Daggerfall which map it is on: `dfb_uz_state.town_map` (the spare `pad1` slot, same offset and size,
   bindings regenerated). 1 outdoors on a town's own Doom map, 0 on the overworld, indoors and during a map change.
2. `DoomerfallAreaLevels.ForCurrentPlace` uses the town level only when Doom reports the town map. Each town
   rectangle keeps its own level (`TownAt`, unchanged). Fixes verifier points 2 and 3.
3. Ammo drop tiers on a town map: Doom asks by 8-tile cell (key 3,000,000 + cell) instead of by map pixel, and
   Daggerfall answers with the town level at the cell's centre, else the terrain level. Fixes verifier point 1.
4. Builds: UZDoom, bridge DLL, launcher (schema hash changes, so all three), Daggerfall Unity.
5. Checks: E1M1 stock and DRLA, the dump, the gate walk extended to walk back in, demo.

## Decisions (engineering calls)

- **Town map flag in the shared state, not an event.** Daggerfall reads it every frame (`DoomerfallBridge.FinishFrame`
  copies it into `DoomerfallAreaLevels.DoomTownMap`). It reuses the padding word, so the layout is unchanged, but
  the schema hash changes and all three binaries must be rebuilt together (they are).
- **Without a Doom session** (Daggerfall alone, as in the `-dfarealeveldump` test) `DoomTownMap` is -1 and the old
  position rule stands in. Daggerfall alone has no Doom map to ask about.
- **Boundary now:** the town level applies while Doom is on the town map, and within that map, inside the town's
  own rectangle + 20 tiles (Doom's exit line, as before). On the way in, the level stays at the terrain level until
  Doom loads the town map (12 tiles out), then becomes the town level. On the way out it drops at Doom's handoff.
  Non-town rectangles on a town map (Privateer's Hold's entrance on Gothway Garden's map, temples) keep the terrain
  level, and a second town on the map keeps its own level, per the designer's decision.
- **Ammo key by cell, not by pixel.** One map pixel can hold parts of two towns with different levels (the City of
  Daggerfall and Ripwych Commons), so a pixel key can't give each its own level. An 8-tile cell (2,048 Daggerfall
  units) is small enough to follow the town rectangle within 4 tiles and keeps requests rare (one per cell entered,
  answers cached for the session, as pixel answers already are). While a new cell's answer is on its way Doom keeps
  the last level instead of sending -1.
- **Indoor rolls are unchanged.** Interiors and dungeons report `town_map` 0, and `ForCurrentPlace` still treats a
  building being laid out as indoors, so tavern piles and the like keep the terrain level.
