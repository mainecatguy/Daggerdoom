# Doom monsters block fast travel

**Waiting on:** owner design. Must be settled before initial release.

Daggerfall blocks fast travel when enemies are nearby, but its hidden world has no enemies because Doom owns the monsters, so the rule never triggers. Decide whether Doom's monsters should block travel, and within what distance. With slaughter-sized packs, a Daggerfall-style check could block travel most of the time. Travel is allowed with Doom monsters nearby until this is decided.
