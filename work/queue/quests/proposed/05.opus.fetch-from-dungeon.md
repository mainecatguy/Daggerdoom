# Quests 5: fetch an item from a dungeon

Read D:\dev\DoomDaggerfall\AGENTS.md first. The survey is `work/notes/20261124-104520-quest-types.md` (type T5,
capability C8, and the moving item note in section 4). This builds on card 4.

## Goal
Quest items at dungeon item markers appear in Doom's dungeon and can be picked up with Use. This type covers 12
quests, and 20 quests place an item in a dungeon.

## What to build
- Send quest items in dungeons, using the dungeon marker position the way quest foes do
  (`DoomerfallMonsters.CollectRows`). Note the dungeon height offset in `GameObjectHelper.cs:1133-1139`.
- Check whether any enabled quest's item marker sits on a moving dungeon action object. Daggerfall parents such items
  to the mover (`GameObjectHelper.cs:1144-1148`). If one does, the Doom item must ride the same mover. If none does,
  say so with the check you ran.

## What must stay true
- Treasure piles and enemy drops in the dungeon are unchanged.
- A taken quest item stays taken after save and load and after re-entry.

## How to prove it
Play `N0C00Y11` (Grab an Ingredient): travel to its dungeon, find the item, take it with Use, see the `clicked item`
message, and turn it in. Then take the item in `K0C00Y08` (A Rare Book).
