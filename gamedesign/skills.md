# Skills

Game design rules for Daggerfall skills in Doomerfall. Owner decisions are dated. Proposals that are not decided are
marked. The first full proposal is `work/notes/20261125-skills-armor-proposal.md` (undecided except where this file
says otherwise).

## Decided

- **No Doom class.** On New Game the Doom player is a normal character with no class effects. Unless a Daggerfall
  skill says otherwise, it has nothing; Daggerfall applies skills and modifiers (owner, 2026-11-25). DRLA classes are
  inspiration for skill effects only.
- **Hand-to-Hand** governs Doom melee: fists and other melee weapons' damage (owner, 2026-11-25, "for now").
- **Archery** stays a skill (owner, 2026-11-25). Its Doom role is not decided.
- Skill effects in Doom are milder than Daggerfall's die rolls, because Doom combat is action based (owner,
  2026-11-25).

## Not decided

Everything else in the proposal: weapon category skills and which skills they reuse, melee consolidation, language
skills, armor as damage reduction, and the classless starting kit.
